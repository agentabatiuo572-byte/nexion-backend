范围：`nexion-backend` 管理端读取投影与专项 PRD；不含 PC/App/H5 页面、文案、权限或新统计合同。

## 1. 背景与原始事实

- 原始待办：`uvel-docs` `origin/main` `handoffs/2026-10-28/backend/20-backend-pending-20261031.md:1582` I1-BE-08。
- `MybatisCopyAbRepository.toExperimentRow` 已调用 `CopyExperimentVariantMapper.listRuntimeMetrics`：
  - 每组的 `COUNT(DISTINCT a.user_id)`（`a.exposed_at IS NOT NULL`）是**去重曝光人数**；
  - 每组的 `COUNT(DISTINCT c.user_id)` 是**去重转化人数**；
  - 当前只用于计算 `cvr`；返回 `CopyExperimentVariantView` 时丢弃，管理端每组没有独立曝光/转化数，实验表只有总曝光/总转化。
- 现有查询没有时间窗口、状态或历史版本过滤：按 `experiment_id` 和组统计，累计至读取时；不是“最近 7 天”，也不是事件次数。
- 组稳定标识：`nx_content_experiment_variant` 的 `experiment_id + variant_name`；`copy_version`、`split_pct`、`sort_order` 在创建实验时写入，之后启动/停止不重写该表。查询以 `variant_name` 关联 assignment/conversion，版本字段固定；当前实现不新增归属规则。
- 总量 `CopyExperimentRow.impressions/conversions` 是同一 runtimeMetrics 列表的求和；组与总量来自同一批指标，不能另拆或补 0 推测。

## 2. 最小实现

只补管理端已有真实值，不改查询、投放或公开接口：

- `CopyExperimentVariantView` 增加 `long impressions`、`long conversions`（加在字段末尾，保留原 4 参/3 参构造器为 0，兼容旧构造调用/序列化消费）。
- `MybatisCopyAbRepository.toExperimentRow` 把已算出的 `impressions`/`conversions` 传入 view。
- 不新增 SQL、聚合、快照、归因、表、缓存或框架；`listRuntimeMetrics` 的 `COUNT(DISTINCT)`、`exposed_at`、无时间窗、累计口径不变。
- 顶层 `CopyExperimentRow.impressions/conversions` 字符串和所有现有字段/顺序不变；组字段是新增 JSON 字段，旧 PC 可忽略。
- 只管理端：`/api/admin/content/copy-ab/overview` 需 `content_i1_read`；`CopyExperimentRow` 由管理端 overview/实验 mutation 返回。App/H5 使用独立的 `AppCopyExperimentService`/`Variant`，不读取该 view，不增加公开返回。

## 3. 空组/缺组/历史状态

- `listRuntimeMetrics` 以 `nx_content_experiment_variant` 左连接 assignment/conversion，故每个未删除组都有行；无曝光/无转化时 `COUNT(DISTINCT ...)=0`，`cvr=0.00`。
- `metric == null` 的既有 fallback 为 0；本候选不把缺失改成 null，也不新增猜测；正常查询下组行存在。
- SCHEDULED/未启动实验没有 assignment，组计数为 0；RUNNING/CONCLUDED/STOPPED/ADOPTED/DISCARDED 等非删除实验均由 `listExperiments` 读取，指标按实验 id 保留；归档/历史版本不改变已有 assignment/conversion，仍可读。
- 曝光要求 `exposed_at` 非空；仅分配未实际曝光不计入。转化要求同一实验/同一用户的 eligible conversion 行；一个用户多笔转化只按用户计一次，不等于订单数/事件数。

## 6. 最少公共 TEST 只读场景（未执行）

1. 选真实存在两组及以上的实验，`GET overview` 与只读 SQL 对照：每组 `COUNT(DISTINCT exposed user)`、`COUNT(DISTINCT converted user)` 一致；组和等于顶层总量。
2. 某组无曝光/无转化：该组返回 0/0，`cvr=0.00`；不把缺失组补成猜测值，不隐藏该组。
3. 一个有多次 eligible 转化/多事件用户：组转化仍按用户去重一次，不是订单/事件数。
4. 只有分配未曝光：不进入曝光；`exposed_at` 后只计一次。
5. 读取已停止/已结束/历史版本实验：指标仍按 experiment id 可读；不改投放/状态。
6. 管理端无 `content_i1_read` 仍 403；App/H5 公开返回不含管理字段；不改权限。
7. 无自然实验/样本时记录未验，不造实验、曝光、转化或用户。
