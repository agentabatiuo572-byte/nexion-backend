# B117 消息中心告警结构字段

消息中心按告警发布时的事实组装显示文字，原因中的 ` · ` 等字符原样保留。三个接口继续提供已有的 `title` 和 `hint`，供旧客户端读取。

| 接口 | 新增字段 |
| --- | --- |
| `GET /api/admin/emergency/geo-block/alerts` | `scope`、`target`、`operator`、`reason`，取自原事件。 |
| `GET /api/admin/emergency/tamper/config-alerts` | `before`、`after`、`operator`、`reason`，取自原事件。`before` 和 `after` 各包含数字 `threshold` 与布尔值 `feedK4`。 |
| `GET /api/admin/users/account-actions/alerts` | `targetUserId` 为目标用户的十进制字符串，保留长编号精度。只读查看的开始和结束事件均取被查看用户的编号。`occurredAt` 为带时区的 ISO 8601 字符串。 |

账户安全接口按成功送达记录读取最近告警，再按原事件号读取业务时间。优先使用原事件记录的发生时间，兼容早期载荷的检测时间和只读查看起止时间。旧事件缺少业务时间字段时，使用原事件表的事件时间，或该事件最初入库的时间。原事件无法读取时，`occurredAt` 为 `null`。仅当原事件或已知的用户级记录能确定目标用户时返回 `targetUserId`，无法确定时返回 `null`。旧地区或配置事件缺少对应结构字段时，字段值为 `null`。

接口沿用地区策略的超管校验、篡改告警设置的专用权限和账户安全的超管或风控校验。地区和设置告警沿用最近 24 小时的成功送达筛选。账户安全告警沿用成功送达顺序，客户端显示时间时使用 `occurredAt`。
