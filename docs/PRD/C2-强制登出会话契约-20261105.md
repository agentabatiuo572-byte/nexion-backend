# C2 强制登出会话契约

`POST /api/admin/users/profiles/{userId}/sessions/revoke-all` 要求 `user_c2_session_revoke_all`、`Idempotency-Key` 和操作理由。没有活跃会话时返回 `409 NO_ACTIVE_SESSION`。

成功返回 `userId`、`status=REVOKED` 和 `revokedCount`。计数取操作前满足有效期和闲置期限的活跃会话数，会话撤销覆盖该用户全部会话。`C2_USER_SESSIONS_REVOKED` 成功审计记录同一计数。相同命令按原幂等规则回放结果。

C2 与 C5 共享 A4 事件 `admin.session_revoked`，业务字段为 `target_user_id`、`operator`、`role`、`reason`、`scope` 和 `occurred_at`。`operator`、`role` 取自认证运营账号。C2 全部登出使用 `scope=all`，C5 单会话撤销使用 `scope=current`。C2 的 `revokedCount` 仅用于接口回包和审计。
