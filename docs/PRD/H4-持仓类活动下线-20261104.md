# H4 持仓类活动下线

日期：2026-11-04。产品决定：整个 holding 活动种类删除，无兼容层。NEX Holders Share 已于 2026-10-29 退役，本次关闭剩余钱包观察触发器、持仓表、规则启用与结算路径。

关联：[BUG-001](../../../uvel-docs/bugs/BUG-001-support-fund-h4-readiness.md)、[BUG-092](../../../uvel-docs/bugs/BUG-092-local-bootstrap-h4-wallet-trigger.md)。本轮读取时 BUG-092 路径不存在；故障事实已与任务 PLAN、原 bootstrap 的 trigger-drop workaround 核对，缺陷记录关闭由协调者处理。

## 业务规则

- 活动种类只接受 discount、referral、wheel、regional、boost、seasonal、onboarding。PC 创建、规则列表、活动列表、启用入口及 App 列表、详情、旧参加/领取入口均不接受退役类型。
- 删除 holders-share 的白名单代码、参数校验、启用时持仓初始化、钱包锁、持仓进度、成员查询与奖池结算分支。结算及待付款调度只处理 regional。
- 遗留 quest 无论草稿、已发布或结束，都置 `status=2,is_deleted=1`；对应规则 `enabled=0`，保留禁用时间、版本及历史业务事实。规则表没有软删除字段，墓碑位于 quest，规则保留停用行以阻止旧 INSERT IGNORE 种子覆盖。
- Genesis 节点持有及其他模块同名概念不属于本次范围。

## 数据迁移

新增 `scripts/migrations/20261104_h4_holding_retire.sql`，重复执行安全：删除 `nx_wallet_h4_holding_observation`、删除 `nx_growth_event_holding`，按规则 kind 或 quest target_type 处理所有 holding 活动。不存在 H4 表时跳过数据更新，不阻断新库。

startup 链在 `20261011_support_fund_journal.sql` 之前下线，保证旧库升级先清除第五条；fresh-db post 在 `20261025_h4_event_rules.sql` 后立即下线，清除每次重放旧文件创建的对象。旧 H4 文件及资金锁定迁移字节不变，Java 原四条钱包 schema guard 和 SUPPORT_PINS 不变。

TEST 通过现有按文件名排序、按历史哈希记账的 runner 自动发现新文件，一次执行后记录 APPLIED。先完成独立 TEST 下线，再部署该迁移；维护版 reader 不进入本地全量 startup 重放。未登记的旧 H4 安装文件继续被通用 stored-program gate 拒绝。
