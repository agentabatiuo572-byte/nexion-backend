# K1 账户组解除与规则放宽的覆盖率

- 解除误判（`released`）和判定为正常（`cleared`）沿用 A2 双人审批。批准执行时以 B1 精确覆盖率与红线比较，恰好达到红线允许执行。有效正覆盖率低于红线返回 `COVERAGE_BELOW_REDLINE`，覆盖率不可用或显示值为零时返回 `K1_COVERAGE_UNAVAILABLE`。失败时账户组、提现限制、审批单和对象锁保持原状态。恢复后可用同一个批准幂等键重试。
- 批准移除该组状态造成的提现限制。其他待处置组、账号数达到现有冻结起点、受保护收益和账户自身状态仍按各自规则判断。
- A2 工单在这两种操作上返回 `coverageCheckOnApproval=true`，供确认文案说明校验时点。
- 新增或重新启用 IP 白名单、延长有效期，以及调大同 IP 24 小时注册、同设备关联或同支付工具关联的账号上限，在保存时执行同一覆盖率检查。停用、缩短有效期、仅修改备注及调低上限继续按原流程执行。
- 定时检测按当前白名单和上限发现新风险。既有待处置组仍需人工处置。即使当前检测没有该组，或关联投影减少了成员，系统也保留原组和原成员的提现限制。规则放宽后没有当前风险信号的组仍可在 K1 查询和处置。
