# B146 验证码挑战有效期

注册、短信登录和找回密码的发码成功回包增加 `expiresInSec`。绑定手机号复用注册发码，也返回该字段。该值以秒为单位，取自创建挑战时使用的 OTP 有效期配置 `auth.risk.otp_ttl_minutes`，默认 300 秒。仍通过 `resendAfterSec` 单独提供重发冷却。已发挑战依据写入时的有效期校验。

短信登录与找回密码的占位回包使用同一个有效期字段和冷却值，保持现有账号信息保护。临时锁定等未创建挑战的错误回包沿用现有格式。挑战到期后的验证码验证沿用原错误码。

手机登录接管与设备激活沿用现行规则。校准、设备绑定和风险检查继续用于激活；条款确认记录不作为激活条件。
