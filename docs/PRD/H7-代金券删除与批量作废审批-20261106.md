# H7 代金券删除与批量作废审批

删除券模板和批量作废未用券提交至 A2。原直接删除及批量作废接口对有权调用者返回 409 `A2_CONFIRMATION_REQUIRED`。

A2 接收 H 域 `h7_voucher_delete` 和 `h7_voucher_revoke_available`，参数为 `voucherId` 和 `expectedVersion`。现有 `growth_h7_write` 授权可发起这两类提案并按原请求键找回本人的票。两类提案使用同一券模板锁。

另一位具有 `platform_a2_operation_approve` 与 `growth_h7_write` 的管理员可批准。执行时核对原票券模板和版本。删除保留已领取的券，批量作废只更新执行时状态为 `AVAILABLE` 的券。执行前及拒绝或撤回时，模板和领取记录保持原样。
