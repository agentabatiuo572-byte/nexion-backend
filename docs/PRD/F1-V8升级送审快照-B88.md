# F1 V8 升级送审快照

B88-BE-04。发起 `F/f_vrank_override` 的 V8 晋升单时，服务端按审批单绑定的用户编号读取原等级，并存入送审时的 V8 晋级奖励模板、V7 与 V8 的好友购买一级和二级比例及月薪。审批对象和原等级由服务端填写。

有权查看该单的账号可在 A2 单据和回执读取 `v8PromotionSnapshot`。`originalRank` 是送审时的实际等级，`v8Rewards` 是送审时的奖励模板，`v7` 和 `v8` 各含 `purchaseL1Rate`、`purchaseL2Rate` 和十进制字符串 `monthlySalaryUsdt`。旧单省略该字段。同一送审键恢复回执时重新核对当前查看权限。

批准时使用当时生效的晋级奖励配置发奖，仍按同人同等级同奖励类型的既有规则去重。送审快照保留供后续查看。
