# BUG-310 H2 强制扣款退役

2026-11-07 用户确认退役旧强制扣款；试用转购继续由用户明确确认购买。

- H2 `POST /api/admin/growth/trials/sessions/{sessionId}/charge` 保留原权限、幂等键与操作理由要求。新请求明确返回 `410 TRIAL_EXPLICIT_PURCHASE_REQUIRED`，不锁定或改变试用记录，不扣钱包、不写扣款账本或购买单；旧后备扣款实现删除。
- A2 新建 `H/h2_trial_charge` 提案在持久化待审批工单、对象锁及成功审计前拒绝；无业务权限仍按原规则拒绝。历史待审扣款的批准同样返回该退役结果，保持待审状态和原锁，仍可按原规则拒绝或由原提交者撤回。
- 历史试用记录、历史审批和原幂等键结果查询保持。已有成功回执仍可核对，重试不会重新扣款；不删除、重写钱包或历史订单。
- 正常试用取消、其他 H2 参数和原权限边界保持。App `/api/trial/convert` 仍通过用户确认的商品、金额、报价版本和支付授权建单；旧自动扣款、提前赎回入口继续退役。

本变更只修改后端业务写入口；PC H2 与 A2 的入口、文案及旧缓存恢复交互需按页面确认门禁单独确认后实施。
