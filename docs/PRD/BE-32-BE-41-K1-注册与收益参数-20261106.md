# K1 注册与收益参数

## H5 注册防刷与新人礼

K1「多账户风险排查」承接原 A3 的三项参数。K1 读权可查看，超管才可保存。A3 目录与原修改接口退出这三个键，A5 参数归属和链接改为 K1。

| 参数 | 可录入值 | 使用时点 |
| --- | --- | --- |
| H5 注册人机验证 | 0 或 1 | 发注册短信时，按原注册验证规则 |
| H5 每设备 24 小时注册上限 | 0–100 | 手机号与第三方新注册共用，0 关闭设备上限 |
| H5 新人礼首购解冻 | 0 或 1 | 仅影响新注册账号，1 需首笔非零购买付款后可发 |

同一参数值、预期旧值、8–200 字理由、操作者和幂等审计沿用原配置逻辑。注册服务继续消费相同键，旧注册记录不迁移。

## 收益审核规则

每簇免费手机号位、放行统计时间范围、免费位需绑定退役。K1 和 A5 不展示，旧修改返回 410 `K1_RELEASE_PARAM_RETIRED`。历史配置行转为非活动，原值和审计保留。促销原生收益规则引用沿用原快照的字段、顺序和历史值，避免仅因退役展示项使既有已批准引用失效。

待审起点至少为 2，且不得超过冻结起点。已保存的两个起点、放宽时的 B1 检查和人工审核放行继续按原规则执行。K1 账户组详情依据有效起点解释收益分流。
