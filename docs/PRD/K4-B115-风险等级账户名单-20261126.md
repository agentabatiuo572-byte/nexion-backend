# K4 风险等级账户名单

今日概览的 K4 风险条目增加 `band` 和 `count`，风险分布的高风险、中风险条目在现有人数 `v` 旁增加 `band`。风险评分页可用 `band` 读取组成该数字的账户名单。采用与首页相同的最高启用模型、分档线、有效分和近一天规则。有效分优先取生效的人工改分，否则取模型分。两处都只统计有评分记录的实际账户，删除、沙盒或无法匹配正式账户的记录排除。

`GET /api/admin/risk/scoring/accounts?band=HIGH&pageNum=1&pageSize=20` 需要 `risk_k4_read`，返回 `band`、`total`、`pageNum`、`pageSize`、`modelVersion`、`bandLowMax`、`bandHighMin`、`autoEscalateScore` 和 `records`。页码从 1 开始，每页默认 20 条，最多 100 条。每页按有效分从高到低，再按 `userNo` 排序。单次读取以同一数据和时间点判断。模型发布、人工改分或评分变化后，刷新可读到新顺序。无有效模型时返回 `K4_RISK_SCORE_UNAVAILABLE`。

| `band` | 范围 |
| --- | --- |
| `AUTO_REPORT` | 当前模型、近一天评分且有效分达到自动上报线 |
| `HIGH` | 当前模型、近一天评分且有效分达到高风险线，包含达到自动上报线的账户 |
| `HIGH_BELOW_AUTO` | 当前模型、近一天评分且有效分达到高风险线、低于自动上报线 |
| `MEDIUM` | 当前模型、近一天评分且有效分达到中风险线、低于高风险线 |
| `STALE` | 非当前模型、评分时间缺失或评分已超过一天，包括待首次评分 |

名单行返回 `userNo`、`effectiveScore`、`modelScore`、`overridden`、`asOf`、`modelVersion` 和 `scored`。`asOf` 使用数据库存储时间所对应的 ISO 8601 时区偏移。缺失的时间返回 `null`。首次评分前 `scored=false`，模型分、模型版本和评分时间为 `null`，只有存在生效人工改分时才有有效分。模型给出的真实零分仍返回 `scored=true` 和 `modelScore=0`。

`GET /api/admin/risk/scoring/users/{userNo}` 使用相同的有效分和未评分状态。待首次评分时本次评分的贡献列表为空，仍可查看已有的操作历史。验收使用相同数据核对首页人数、各档名单和单人有效分，检查跨页顺序、时区、空时间、孤立记录过滤和权限。

`GET /api/admin/risk/scoring/users` 找人候选也返回布尔字段 `scored`，与单人详情共用判断。待首次评分或当前仅有人工改分的账户返回 `scored=false`，已有模型评分即使为零也返回 `scored=true`。候选的既有摘要、分数与分档字段沿用旧读取合同。页面接入时按 `scored` 决定是否显示模型评分及档位。
