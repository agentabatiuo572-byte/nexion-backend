# BE-17 和 BE-24 团队费率启用与等级写入

首次启用 F2 七层结算时，A2 发起申请和批准执行均检查 L1 至 L7 的有效 USDT 比例与 UVT 系数。合法的零费率计为已配置。费率不齐时不能进入首次启用，原结算模式与版本维持。暂停和恢复沿用现有状态与版本规则。

新配置和等级写入使用 V0 至 V8。F4 解锁门槛与票权保留其 V1 下限。旧的高等级解锁门槛原值可读，修正前结算继续显示配置阻断。历史 V9 至 V12 用户等级、筛选和既有记录继续可读。

验收在隔离库进行。F2 用缺少单层、补齐且有合法零费率、申请后费率缺失三个状态验证 A2 提交、批准和结算模式回读。F4 对解锁门槛及票权分别验证 V9 拒绝、V8 可写，保留旧配置阻断。F1 对有活跃历史等级配置的用户验证拒绝写入 V12，再按 V12 筛选核对原记录。
