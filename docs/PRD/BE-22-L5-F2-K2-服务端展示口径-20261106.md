# BE-22 L5、F2、K2 展示口径

- L5 安全参数显示用户名单最多 5,000 行，财务资金明细、团队树、账单各最多 100,000 行。用户名单最多取前 5,000 行，后三类超限时需缩小范围。
- L5 以「当前披露快照」称呼按当前生效披露版本生成的产物。任务及导出记录沿用原类型、权限和已生成的 CSV 快照。
- F2「团队购买奖励」显示「L1 成员占比」，值取一级成员数除以全部团队成员数。
- K2「试用循环」表头使用当前试用循环检测规则的天数。刷榜卡及说明使用正式页面名「奖励池、名额与排行榜」。

## 2026-11-16 补充：F2 USDT 比例的百分数点合同（BUG-428）

F2 `usdtRate` 的保存值和放大方向统一按百分数点解释，输入可以带或不带 `%`：`0.5`/`0.5%` 为比例 `0.005`，`1`/`1%` 为 `0.01`，`5`/`5%` 为 `0.05`。原读取仍将存储比例乘以 100 返回百分数点；A2 预览、方向比较和批准回放使用同一转换。

换算只应用于 F2 两个调用点，保留既有除以 100 后 scale 6、HALF_UP；全局比例解析、F4 两个头部上限方向和覆盖率可靠性字段不改。超过四位百分数的精度、旧错误行及历史奖励结算不在本单位子范围。本轮不改 PC 输入、确认框或文案，真实审批、落库读回及结算仍待新 TEST 验收。
