# 新 TEST：Cloud Share 规格说明与在线率

2026-11-15，用户要求完善Cloud Share商品GPU、显存、功耗和在线率，查找既有产品文档及设计；明确由执行方按产品定位确定内容，随后要求在线率只显示百分比，不显示“目标”。前端代码保持不动，不创建真实订单。

正式词典A-13及既有英文白皮书将Cloud Share定义为虚拟算力份额。原型GPU为Distributed、物理显存和功耗为0，不能据此声称新TEST存在特定独占显卡、GB或0W服务器。E1的Share编辑表不提供功耗输入，后端原先将0显存投影为unavailable，造成App规格表四个缺值。

本次以现有canonical productType=SHARE作为显示判断，仅在零/空显存时返回“不适用（虚拟算力份额）”、空功耗时返回“不适用（非独立设备）”；正显存及已有非空功耗保留，实体商品原投影不变。没有改变数据库的物理显存0、任务路由等效能力、资源分配、购买资格、库存或任何金额。

GPU和在线率继续由E1配置并经A2双人审批：Cloud Share采用“共享计算资源”和99.9%；五款实体设备将原“目标 99.9%”改为99.9%。在线率为用户指定的运营配置展示百分比，不记录或生成历史实测遥测，不新增赔付规则。

App/H5及接入同一新TEST后端的H5 Lite会读到同一商品参数：商品详情四行，搜索、团队购买配额及锁定商品卡的GPU/显存摘要同步。此为SKU自定义中文说明，不新增自动翻译，不改前端布局、路由或交互，不修改fleet设备遥测。
