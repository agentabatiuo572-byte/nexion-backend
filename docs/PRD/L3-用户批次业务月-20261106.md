# L3 用户批次按业务月筛选

BE-18（L-D20）适用于 `GET /api/admin/bi/finance/redemption` 的 `cohort=YYYY-MM`。用户按注册时所在的业务月归入批次。L3 使用与 L1、L2 一致的 LEGACY 业务日历和对应日期生效的时区版本。

以业务月首日零点为起点、下月首日零点为终点，换算成存储时间后筛选注册记录。起点计入当月，终点计入下月。当前与前期兑付统计使用同一注册批次，提现事件的统计周期独立。未选批次时仍读取全部，月份格式校验和响应字段沿用现有契约。

保留原注册时间、提现事件和已生效的历史业务日历版本。后续时区版本只影响其生效边界，历史数据不回写、不重算。
