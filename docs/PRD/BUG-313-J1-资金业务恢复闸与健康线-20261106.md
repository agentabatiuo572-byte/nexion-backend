# J1 资金业务恢复与健康线

J1 手动恢复和关联业务恢复共用 B1 恢复门槛。受资金预检约束的开关须取得可靠估值，并按未舍入的储备和负债判断是否达到红线。精确值低于红线或估值不可用时拒绝恢复，原开关保持关闭。关停操作按原权限立即执行。拒绝审计包含估值可靠性、精确红线结果、触发入口和操作原因。

`GET /api/admin/emergency/kill-switches` 的 `coverage.yellowLinePct` 取 B1 配置的 `healthyPct`。`coverage.valuationReliable` 表示估值可用性，`coverage.recoveryAllowedByServer` 表示上述实际恢复门槛。现有 PC 解析器要求旧 `recoveryAllowed` 等于显示比例与红线的比较结果，该字段按原格式兼容。

PC 接入项为使用 `valuationReliable` 和 `recoveryAllowedByServer` 展示估值不可用和控制恢复入口，并采用 B1 健康线称谓。旧 PC 的恢复请求已受后端精确门槛约束。
