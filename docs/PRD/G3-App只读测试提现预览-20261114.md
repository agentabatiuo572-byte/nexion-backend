# G3 零波动与 App 只读测试提现预览

## G3 合同

周曲线允许零波动，与运营端既有非负规则一致；负数或缺失波动、缺失曲线及其他无效字段仍拒绝。新 TEST 经授权的七天目标价均为 0.001 USDT/UVT，上涨概率与波动均为 0，引擎暂停，自动推进未配置。业务配置初始化与当前现价发布由操作员备份及回执单独记录，不生成过去价格历史、不变更钱包资产、不启用兑换或真实出款。

## 测试预览入口

- `GET /api/withdrawals/test-preview` 使用正常 USER 认证、活跃账户及非 sandbox 账户检查。仅严格单一 `dev` profile 且部署属性 `nexion.withdrawal.test-preview.enabled=true` 可用；属性默认 false，其他运行态或关闭时返回 404。
- 可选 `amount` 为正数且最多六位小数。不传金额只读取元数据；传金额时仅检查既有最低金额、BEP20 固定费用、真实可用余额、余额比例限制和业务日次数上限。未知钱包或配置继续报错，不用默认费用、余额或业务参数补齐。
- 明确返回 `testPreview=true,readOnly=true,canSubmit=false` 和校验范围 `amount-fee-balance-limits-only`。`validationPassed` 仅表示所列参数校验结果，不表示地址、K3/K4、合规、可提现资金来源或真实通道资格。费用不使用 UVT 抵扣，展示净额仅为金额减既有固定网络费用并以下限 0 截断。
- 不调用真实 eligibility/submit、风险评估、网关或 LOCAL；不修改开关、网络能力、profile 隔离、余额、预占、账本、提现单、幂等记录、审计或事件。真实提现保持原有关闭/缺配置拒绝。

## 验收标准

默认关闭时元数据 404、App 不显示入口；新 TEST dev 显式启用后正常用户可打开预览，余额 0、金额 50 返回 `INSUFFICIENT_BALANCE`，可见费用和限额。未登录拒绝，prod/test 或 sandbox 账户不获得预览。金额格式和读取失败不展示成功；切账号、环境或离页丢弃旧响应。对照前后钱包、提现单与账本无业务写入。G3 七天零波动能够通过公开行情读取，其余非法合同仍拒绝。
