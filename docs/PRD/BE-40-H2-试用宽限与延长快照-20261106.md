# BE-40 H2 试用宽限与延长快照

成功领取或重新领取试用时，后端与试用天数、商品及收益一起保存当时的 `graceDays` 和 `extensionDays`。后续修改 H2 配置只影响之后的领取。已领取的试用在 App／H5 状态接口中继续使用 `config.graceDays`、`config.extensionDays` 原字段，值来自该次领取。可重新领取时，状态接口提供最新配置。

宽限截止是原试用截止加快照宽限天数。转购截止校验、定时到期扫描、锁单后的到期复核和宽限截止提醒使用该时间。延长成功后，截止时间是原试用截止加快照宽限及有效延长天数，并作为该次延长的绝对截止时间保存。已延长的试用及其截止提醒继续使用已保存的截止时间。宽限可配置为 0 天，延长沿用原有至少 1 天的执行口径。

升级前停旧后端。没有历史快照的进行中试用，按同一用户、领取请求键和领取编号匹配现存的成功领取回执，从中恢复有效的天数。缺少有效历史值时，以迁移时的有效 H2 配置补齐一次。迁移只补齐缺失字段，保留已保存的截止时间、历史终态、版本和原命令回执。重复执行迁移不会覆盖已记录的快照。

验收覆盖更新配置前后的两次真实领取，分别读回宽限截止、执行延长及定时关闭，并核对同键重试及升级后的旧试用。延长资格阈值继续按实时配置判断。
