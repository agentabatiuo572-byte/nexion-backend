# E6 手机生命周期时间精度

## 问题与行为

手机校准激活将 `purchased_at`、`activated_at` 写入秒精度 `DATETIME`。原写入使用 `NOW(6)`，在秒后半段可能向上舍入到下一秒；紧接的正常 phone-online 请求使用业务时钟微秒值，E3 因生命周期开始时间在请求之后而返回 `E3_DEVICE_LIFECYCLE_START_INVALID`。

手机新建及重新激活时，这两个字段按实际存储精度使用 `NOW()`；已有 `purchased_at` 保留原值。业务时区继续为 Asia/Shanghai，数据库应用连接仍使用 +08:00。E3 对未来生命周期时间的拒绝规则保持不变，绑定和审计的微秒时间保持不变；不通过等待、放宽校验或改历史设备时间消除错误。

## 整体业务验收

用新的普通隔离账号，经登录、正常校准，在秒后半段发起激活并立即调用 phone-online，验证激活成功、在线确认成功且正常生成规则任务，再验证任务完成后的凭证与账本。记录请求时刻与设备生命周期值；重试早已激活的旧设备不能代替本场景。此处描述验收要求，实际结果以本轮业务证据为准。
