# B35 提现免审金额线与零天窗口

依据：[B35 产品要求](https://github.com/agentabatiuo572-byte/uvel-docs/blob/main/handoffs/2026-10-28/backend/20-backend-pending-20261031.md#b35-窗口-0-天时小额免审线也要生效产品-2026-11-07)。

2026-11-08 更新：USDT-BEP20 / USDT-ERC20 的 H1 等待与人工审核以 [D5 / H1 加强合规与大额窗口](D5-H1-USDT加强合规与大额窗口-20261108.md) 为准：关闭不附加 H1 等待；开启所有新单人工，严格大于 1,000 USDT 才附加 N 天，零天与到期均不等于自动通过。下列正天数 USDT 自动复核描述是此前交付口径，已被本次两网规则替代；BANK-VND 与原审核路线快照契约保留。

- 小额免审线为正数且本金不超过该线、未到强审金额、K4 为低风险、K3 为 `pass`，才可自动审核。线为 0 时关闭小额免审。
- USDT 在零天及正天数窗口都执行金额线；正天数仍等待原 H1 冷却期。越南盾仅在零天窗口且符合上述条件时自动审核，正天数仍走人工审核。
- 合格新单提交为 `EXTENDED_HOLD`、`previousStatus=REVIEW_PASSED`，由 `H1_ZERO_DAY_AUTO_REVIEW` 或 `H1_PHASE_COOLDOWN` 管理；到期仍复核现有风控、关停和资金覆盖门槛。超线普通新单为 `REVIEW_PENDING`，不获得 H1 自动审核 owner。K3 延迟、冻结及高风险处理保持原流程。
- 资格预估与实际提交共用免审结果；消除低风险 `fast-pass` 回退绕过金额线的路径。
- 新单将提交审核路线写入可空字段 `d2_submission_risk_route`。详情、列表、银行卡提交和恢复读取此快照，生命周期释放及审计归档不改变它。历史单不回填、不重审，继续原读取兼容。

## 发布与回退

先通过正式启动迁移链应用 `scripts/migrations/20261107_b35_withdrawal_review_route.sql`，再部署候选后端。迁移只新增可空列，可重复执行；缺列时启动失败并给出迁移指引。旧版本可保留该列回退，不删列、不更改存量单。
