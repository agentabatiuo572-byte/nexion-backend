# B30 历史放行规则与任务归档写入

K3 历史放行规则仍可查阅，并可按原状态流停用和归档。尝试启用时返回 `422 K3_LEGACY_PASS_ENABLE_FORBIDDEN`，原状态和版本保持原值。

H3 任务归档后，原译文保留可读。任务名的译文写入口使用同一任务状态，归档后返回现有的任务状态流拒绝响应。活跃或暂停的任务沿用原译文写入流程。

## 2026-11-17 H3-BE-04 接续：从未开放草稿的基础三语撤回

依据 `uvel-docs` / `origin/main` `handoffs/2026-10-28/backend/20-backend-pending-20261031.md` 的 H3-BE-04：既定规则是草稿可以撤回、开放后不能；此前只有附加语言允许清空，暂停状态不能证明从未开放。

- 新增持久技术字段 `nx_mission.content_state`：`DRAFT`（由当前建单入口写入）、`OPENED`（暂停→启用的状态转换写入）、`UNKNOWN`（迁移前存量及非该建单入口写入）。字段只表达内容生命周期证据，不新增页面状态、任务类型或奖励政策。
- 仅当任务同时满足 `content_state=DRAFT` 且当前 `status=paused` 时，`content.mission.<code>.name.zh/en/vi` 的空值才表示撤回；已有非空值仍按原版本/幂等/理由/审计流程保存。
- 存量 `UNKNOWN`（包括当前暂停的旧任务）不因暂停或历史为空被当成草稿，基础三语仍不可清空；已置 `OPENED` 的任务同样不可清空。附加六种语言的原清空规则不变，事件的本地化写入不变。
- 任务目录读取（`missionRows`，供 `dayOneTasks`/`weeklyTier1`/`weeklyTier2` 及同一 `questTasks` 响应）新增并原样返回 `contentState`；值为 `UNKNOWN`/`DRAFT`/`OPENED`，不从 `status` 推断，不改变原任务字段、权限或排序。
- 初始化只走既有 `scripts/migrations` 启动路径；不在 GET 或业务事务内执行 DDL。老数据不回填 `DRAFT`，不伪造发布历史；未执行真实数据库或 HTTP 验收。
