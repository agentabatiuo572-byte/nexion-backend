# H3 已存奖励策略读取兼容

已存的首日任务三段奖励策略可以使用历史 NEX 后缀。读取时仅将该后缀投影为当前 UVT 语义，继续按原三段数值、冻结全奖与资格时窗、倍率和节奏月计算；不改写现有配置、实例、快照摘要或已发奖励，不用当前配置重算历史。

首页和任务中心读取已有实例时，已过期实例的当前阶段奖励仍为 0。资格窗内的合法旧实例沿原合同领取，仍须满足完整冻结成员组、任务完成、资格窗和一次领取要求，沿用原幂等编号、金额精度和资金校验；过期、缺失成员、重复领取及非法策略仍按原规则处理。读取兼容不补发或重置任何奖励。

注册读取合法旧配置创建新首日实例时，保留相同奖励数值并将新实例策略冻结为规范 UVT 文本；已有实例直接复用，不重建。后台新提交的策略继续只接受 UVT，原金额、三段关系、精度、时窗及资金放大审批规则保持不变。

此改动仅恢复后端已存策略读取和原合同执行，不包含 App、H5 或管理端页面单位、文案、布局和交互调整。
