# E2 任务定价初始化与维护

## 启动初始化

任务奖励下限或上限为 0 是已保存的有效配置。应用重启与整库安装保留已有奖励、模型、最低显存和停派状态。Java 只对旧表刚扩列时模型与显存均为空的规范任务补默认值，沿用该行原来的任务状态和停派值。

Bash 与 PowerShell 都在任务目录建好后执行 E2 初始数据脚本。只有某类从未配置正式任务时才补该类的规范默认任务。已有正式任务优先保留，包括由非规范 ID 提供的定价。历史软删除记录保留。手机档位继续从 `nx_onboarding_phone_tier_config` 读取。

## 当前任务维护范围

当前新任务维护只接收 `poolCode=PHONE` 的手机模拟任务，使用任务池及模拟策略入口维护任务类型、固定奖励和启停状态。更新策略时携带当前模拟策略版本；涉及审批的变更继续走现有 A2 提案和批准回放。旧通用任务目录供历史读取，不能以收紧或等价为由继续通过旧入口新增、修改或删除目录任务。

`E/e2_task_lifecycle_change` 属于退役的通用目录维护合同，不是当前手机任务的新维护入口。保留历史实现或历史票据不表示重新开放该合同；不得为迎合旧文档恢复旧接口。当前手机模拟任务以 `TaskPoolService`、手机类型校验和不可变模拟策略版本为准，App 已领取任务仍保留发放时的奖励快照。

手机档位奖励、E2 平台参数及启动默认数据继续使用各自既有入口，本次文档对齐不改变其权限、审批或运行配置。
