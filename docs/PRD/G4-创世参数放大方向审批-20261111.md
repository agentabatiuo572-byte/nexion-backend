# G4 创世节点参数放大方向审批（A01、A02、A04～A08）

2026-11-11 · BUG-286 · 后端 · 口径依据产品 T11 补充（`uvel-docs/admin-console/decisions.md` T11-4）

## 生效规则

`PATCH /api/admin/market/nex/genesis/params/{paramKey}` 的写入按参数分别判定「放大资金流出」的方向，放大方向必须先取得 A2 双人审批票；收紧方向仍直接写入。A2 复用通用 `G/g4_genesis_param` 命令，不新增专用 op。

| 参数 | 编号 | 必须先审批 | 仍直接写 | 应付 Δ |
| --- | --- | --- | --- | --- |
| `supply` 节点总量 | A01 | 提高 ACTIVE 系列真实总量 | 降低或等额（仍受已售下限、100,000 上限与末档起点校验） | 0，只查当前覆盖率 |
| `price` 一级购买单价 | A02 | 提高系列单价 | 降低、等额 | 现存合格同系列持仓逐笔「新日分红 − 旧日分红」求和 |
| `royalty` 内部转售手续费 | A04 | 按生效的整数基点比较，降低 | 提高、等额、亚基点级变化 | 0，只查当前覆盖率 |
| `airdropPct` 释放分配占比 | A05 | 任何改动 | 无（等价改动被 `G4_GENESIS_PARAM_VALUE_INVALID`/无变化拦截） | 0 |
| `emissionCurve` 释放曲线 | A06 | 任何改动 | 无 | 0 |
| `airdropLockDays` OG 倍率锁仓期 | A07 | 任何改动 | 无 | 0 |
| `divBase` 每日收益基数公式 | A08 | 任何改动 | 无 | 0 |
| `showcaseEnabled` App 商城入口 | A09 | 不审批 | 展示开关保持直接写 | 不适用 |
| `dividend` 每日收益比例 | A03 | 见 `G4-分红审批与真实补发.md` | — | 见该文件 |

- 放大直写返回 `409 G4_GENESIS_PARAM_APPROVAL_REQUIRED`，不落库、不写审计、不产生业务事件。
- `royalty` 落库列为 `nx_genesis_series.royalty_bps`（INT），因此方向判定按 `pct × 100` `HALF_UP` 后的整数基点比较；`2.5% → 2.4999%` 这类亚基点改动不算放大。
- A05～A08 按产品口径视为说明性配置：修改走审批、不计应付，本次不为它们新增释放或公式执行功能；分红仍按 S01 固定公式（系列价 × 持有量 × 日比例）。
- 无 ACTIVE 系列的纯目录维护沿用原行为：不查覆盖率，开售那一刻再由独立闸门检查。

## 拟值覆盖率 Δ

不预测未来的量。审批时只把这次改动确定能算出的新增应付 Δ 加进应付款，检查「储备 ÷（应付 + Δ）」不破红线；算不出确定新增的，Δ 取 0，只查当前覆盖率。提案时算一次，批准回放时按当时的数据重算。

- `price` 的 Δ 与 G4-A03 同一算法：对现存合格同系列持仓逐笔计算新日分红减旧日分红，逐笔按 `HALF_UP` 保留六位后求和，负差计 0。
- A01 总量提高、A04 手续费降低、A05～A08 说明性配置的 Δ 均为 0。
- 覆盖率不可靠（`ratioReserveUsd`/`ratioLiabilitiesUsd` 缺失或 `redlinePct` 非正）返回 `503 B1_COVERAGE_UNRELIABLE`；Δ 计入后破线返回 `422 COVERAGE_BELOW_REDLINE`。

## A2 合同

- 复用既有通用命令：`command.domain=G`、`command.op=g4_genesis_param`，`sourceDomain=G4`，`obj` 与 `target.id` 为该参数键，`params` 携带 `paramKey`、`value`。发起与批准的业务权限按各参数原有直写权限校验（`finprod_g4_write`、`finprod_g4_price_write`、`finprod_g4_royalty_write`、`finprod_g4_airdrop_pct_write`、`finprod_g4_emission_curve_write`、`finprod_g4_airdrop_lock_days_write`）。
- 批准回放直连 `OpsNexMarketService.updateGenesisParam`，不经过 `G4AdminCommandService`，因此 A05～A08 的回放不需要 `decisionRef`；直接写入口仍按原规则要求 `decisionRef`。
- 批准时按当时数据重算 Δ 与覆盖率，不以提案时的快照为准；参数原值已改变导致方向变为收紧时，回放按当时值写入并只查当前覆盖率。
- 回放保留原幂等键、`G4_GENESIS_PARAM_CHANGED` 领域审计、`decisionRef` 与末档/档位版本审计字段。

## 未交付边界

- PC 页面本阶段未改：页面仍按 `param.b1RedlineTriggered` 一次性提示，未接 A2 提案流程；未接入的页面直接放大将收到 `409 G4_GENESIS_PARAM_APPROVAL_REQUIRED`。
- A02 的页面与后端说明里「只影响后续购买」已不成立（系列价会立刻改写现存持仓的每日分红），文案修正见 BUG-421。
- 本文件不代表 G4 全组关闭：市场开闭、熔断、H1 收益门仍走各自准入。
