# BUG-166 B1 覆盖率序列采样间隔

`GET /api/admin/treasury/b-domain` 在 `data.dualLedger.snapshot` 中增加整数 `coverageSeriesIntervalHours`，表示 `coverageSeries` 相邻两点之间的小时数。当前序列按从旧到新排列，共 8 个点，间隔 3 小时，首尾跨度为 `(8 - 1) × 3 = 21` 小时。末点对应 `data.dualLedger.generatedAt`。

每点以当前储备扣除该点至快照时刻的已确认净流入回推储备，储备最低为零，并以当前应付款计算覆盖率。B0 差额卡用这组覆盖率和当前应付款推导趋势，时间跨度按实际点数及间隔计算。B1 样本的计算口径、读取权限及 D3 净敞口的 7／30／90 天窗口沿用现行契约。
