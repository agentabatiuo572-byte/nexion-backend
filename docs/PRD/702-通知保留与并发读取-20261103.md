# 702 通知收件箱保留与并发读取

App 按当前登录账户读取通知。分页按通知 ID 降序，分类、优先级及游标只限制本页。返回的未读数涵盖同一快照中该账户全部可见的未读通知。投递状态和用户偏好继续决定可见性，关键通知必收。

| 优先级 | 每账户保留规则 |
| --- | --- |
| critical | 永久保留，标记已读后也不能通过清理已读删除。 |
| high、normal | 按各自启用的后台上限保留最新记录。按创建时间排序，时间相同取较大的通知 ID。 |
| low | 同样按该档上限保留，创建时间早于当前时间 48 小时的记录同时淘汰。 |

打开列表时先完成该账户既有的提现通知补投，再处理确实超限或过期的记录。没有待淘汰记录的轮询只读取保留数据。需要淘汰时逐条按主键软删除，只处理优先级和创建时间仍符合本次判定的记录，在处理下一条前释放上一条的锁。已淘汰记录不因清理其他已读通知或调高上限重新出现。

后台派发及调整上限仍在各自写事务内按账户排名、淘汰超限记录并清理过期低优先级通知。单条或批量标读仍校验账户、投递状态和偏好，原有通知读取事件与写入一同提交。
