# BUG-333 D3 应付款与净敞口估值状态

`GET /api/admin/treasury/liabilities?breakdown=true|false` 和 `GET /api/admin/treasury/net-exposure?window=7d|30d|90d` 继续使用现行权限、查询参数和成功响应结构。两接口增加 `valuationReliable`（布尔值）和 `valuationStatus`（`AVAILABLE` 或 `VALUATION_UNAVAILABLE`）。`AVAILABLE` 表示相关金额可估值，也包含实际应付款为零的情况。

UVT 应付量取生效锁仓本金与预计奖励之和。UVT 应付量为零，或最近一条生效的 UVT/USDT 价格大于零，即可估值。存在 UVT 应付量且最新价格缺失、为零或为负时，估值不可用，与 B1 当前价可靠性口径一致。应付款总额覆盖全部九类；净敞口按现行预测配置筛选科目，只有远期和 UVT 科目都纳入时，才受该 UVT 估值影响。

| 响应 | 权威估值字段 | 估值不可用时 |
| --- | --- | --- |
| 应付款 | `valuedTotalUsdt` | `null` |
| 应付款 `breakdown` | `valuedAmountUsdt`、`valuedShare` | UVT 行金额为 `null`，其余科目金额继续返回；所有占比均为 `null` |
| 净敞口 | `valuedCurrentNetExposureUsdt` | `null` |
| 净敞口 `series` | `valuedLiabilitiesUsdt`、`valuedNetExposureUsdt` | 两者均为 `null`；日期和储备金额照常返回 |

估值可用时，新字段与对应的原金额或占比相等。旧版 PC 的数值校验需要原 `totalUsdt`、`amountUsdt`、`share`、`liabilitiesUsdt`、`netExposureUsdt`、`currentNetExposureUsdt` 和 `negative` 保持现行类型。新调用方按上述权威字段读数，`VALUATION_UNAVAILABLE` 时不得用原字段得出应付总额、占比或资金富余结论。`breakdown=false` 仍不返回科目行。

PC 按本轮确认范围单独接入和验收。D3 应付款卡片、UVT 行和占比降级，配置口径缺价时差额图不画资金富余或不足。旧 B2 应付款总额和兑付覆盖率降级，避免把缺价显示成「无应付款」。B1 趋势使用净敞口估值状态，独立的当前覆盖率和差额使用已有 B1 全口径估值可靠性。储备、7／30 天到期预测和配置读数可分别继续显示。页面实际验收需覆盖有效价、缺价、恢复价、零 UVT 应付和 D3 预测排除远期科目。L3 财务快照嵌套应付款响应，可读取新增字段，页面接入另核。

本次读取契约沿用预测预览、CSV 和 J1 接口现行合同。当前 CSV 无估值状态列，缺价时应付款和对账仍可能低报。后续若接入导出降级，可保留现有列、理由、权限及原键回执，缺价时以空金额和占比标记无法核算的单元格，并提供明确估值状态。已生成文件的同键重放按原快照处理。J1 恢复门槛是 BUG-313 的独立写路径。
