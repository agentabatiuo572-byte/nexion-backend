# BE-39 预测配置提交前只读预览（BUG-171）

`POST /api/admin/treasury/forecast-config/preview` 接收与保存相同的业务字段：`reserveCategories`、`liabilityCategories`、`forecastWindow`、`genesisIncluded`、`includeFarLiabilities`、`stakingInterestMode`、`trialStressEnabled`、`expectedVersion`。不要求或使用操作理由、操作者、`Idempotency-Key`。权限与保存相同，仅 `finance_d3_write` 或 `overview_b2_write`，不授予只读角色。

返回 `{before, after, forecastDeltaPreview, effectiveAt, version}`；`version` 是本次读取的当前配置版本，保存仍须提交此 `expectedVersion`。`effectiveAt` 为拟保存后次日 UTC 00:00。已有合法 pending 时，`before` 使用 pending 编辑起点，包括已经到时但尚未被正常读取推进的 pending；预览只虚拟读取，不推进 active、版本或历史快照。没有 pending 时使用现行 active。预览不是锁定报价，确认提交时保存会重新校验版本和计算金额。

预览与保存共享配置规范化、科目校验和金额算法。缺少或负数版本返回 `400 D3_EXPECTED_VERSION_REQUIRED`，旧版本返回 `409 D3_FORECAST_CONFIG_VERSION_CONFLICT`；科目、计提方式及窗口错误与保存相同。新请求只允许 7／30 天；旧 active／pending 90 天保持可读，但继承 90 的草稿也必须显式改成 7／30 才能预览或保存。

`forecastDeltaPreview` 保留原有每日创世及 7／30 天改前、改后、差额字段和科目变更计数；每日创世字段同时尊重创世纳入态与其科目开关。增加以下字段，保存回执同步返回同一结构：

| 字段 | 含义 |
|---|---|
| `beforeReserveUsdt` / `afterReserveUsdt` / `reserveDeltaUsdt` | 按配置筛选的储备分子及变化量；与 D3 使用同源可用储备，其他流动资产现行权威值为 0 |
| `beforeLiabilitiesUsdt` / `afterLiabilitiesUsdt` / `liabilitiesDeltaUsdt` | 当前九类全额应付款按科目、创世、远期开关筛选后的分母及变化量；与差额曲线现行口径共用实现 |
| `beforeNetExposureUsdt` / `afterNetExposureUsdt` / `netExposureDeltaUsdt` | 分子减分母，以及改后减改前的净差额变化 |
| `beforeCoveragePct` / `afterCoveragePct` / `coverageDeltaPct` | 分子÷分母×100，六位小数；变化量单位是百分点 |
| `beforeCoverageStatus` / `afterCoverageStatus` | `AVAILABLE` 可计算；`NO_LIABILITIES` 分母不大于 0；`VALUATION_UNAVAILABLE` 纳入 UVT 远期应付款但缺少有效估值。后两种状态对应覆盖率及其差额为 null |
| `coverageScope` / `coverageFormula` / `coverageNote` | 明确为 `CONFIGURED_FULL_LIABILITIES` 配置口径，附公式与说明 |
| `removedLiabilityCategories` | 改前纳入、改后退出分母的科目键，包括由创世或远期开关退出的科目，供 PC 警示 |

该覆盖率的分母是筛选后的当前全额应付款，不是 7／30 天到期额；试用压力层可叠加到期预测，但不进入该全额分母。配置口径预览不改变 B1 按完整应付款计算的安全覆盖率、红线判断或已确认的财务事实。覆盖率不可计算时显式返回 null，不伪造 100%；PC 不得将不可计算状态默认为「100%」或「预检完整、可以确认」，须呈现状态并落实确认门禁。

预览服务使用只读事务，不写配置、审计、outbox 或命令幂等记录，也不通过储备面板的水位计算触发 pending 推进；正常安全认证、会话与拒绝访问记录沿用全局安全机制。保存的理由、幂等、下一日生效、必达审计与 outbox 规则保持。

PC 由后续页面任务接入：确认框加载此接口，展示改前／改后预测金额、净差额、配置口径覆盖率和退出分母警示；加载未完成或失败时不得确认。此交付仅为后端接口，不代表 PC 入口或页面验收完成。
