# F4 大使申请规则与原提交回执

## 启动时的默认规则

全新库由启动种子创建 F4 策略表并插入 `ambassador-v1` 默认规则，默认预算为 3,000 USDT，包含场地、创作者、印刷与户外广告、开发者活动四个分类。Windows 和 Bash 启动迁移只在缺少 `default` 记录时补种。库内已有默认记录时，保留预算、分类、修订、更新时间和启停状态，包括已停用或已软删除的记录。已登记的受管迁移及其校验值按原发布记录保留。

PC 与 App 读取同一已生效版本。以旧修订发起的 A2 变更仍按当前修订校验，重启后仍拒绝过期提案。

## 已提交申请的原键恢复

通过登录、V5 资格和原有提交格式及日期校验后，App 按本人账号、当前运行范围和原幂等键查询。载荷相同返回已有申请和实际提交金额。载荷不同返回 `409 IDEMPOTENCY_PAYLOAD_CONFLICT`。此查询先于现行预算规则，预算收紧后仍可恢复原回执。新申请使用当前生效的分类和预算，超出范围返回 `422 AMBASSADOR_APPLICATION_INVALID`。原申请仍可通过本人历史查询。
