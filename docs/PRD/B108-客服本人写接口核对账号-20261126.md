# B108 客服本人读写接口核对账号

客服在页面看到账号 A 后，如果另一标签页切换到账号 B，后端必须拒绝仍指定账号 A 的原读取或写入操作。即使随后切回账号 A，也不能把账号 B 读到的邀请码、链接、二维码或头像带回原页面。

| 接口 | 操作 |
| --- | --- |
| `GET /api/admin/content/support-agents/self/invite-code` | 读取当前邀请码 |
| `GET /api/admin/platform/accounts/self/avatar` | 读取本人头像快照 |
| `GET /api/admin/platform/accounts/self/avatar-assets/{id}` | 读取本人头像素材预览 |
| `GET /api/admin/platform/accounts/self/avatar/content` | 读取当前本人头像的图片 |
| `POST /api/admin/content/support-agents/self/invite-code` | 生成或重置邀请码 |
| `POST /api/admin/platform/accounts/self/avatar-assets/default` | 准备默认头像 |
| `POST /api/admin/platform/accounts/self/avatar-assets` | 上传头像 |
| `PATCH /api/admin/platform/accounts/self/avatar` | 保存头像 |
| `DELETE /api/admin/platform/accounts/self/avatar-assets/{id}` | 取消头像素材 |

客户端可在 `X-Expected-Admin-Id` 传入当前页面所对应的管理员编号，格式为无前导零的正整数十进制。后端使用该请求已认证的管理员身份核对。请求头为空、格式无效、重复提供，或编号与当前管理员不同，返回 HTTP 409 和 `SELF_ACCOUNT_MISMATCH`。校验在进入读写服务前完成。读取被拒绝时只返回错误，不返回邀请码、头像快照或图片；写入被拒绝时不会变更邀请码、头像素材或账号，也不会写入或返回该命令的成功回执。

请求未携带该头时兼容旧客户端。账号一致的请求继续走原有客服资格、版本、素材归属和命令号规则，图片读取使用原有响应类型和缓存规则。管理员代办和共享命令回执接口沿用各自规则。
