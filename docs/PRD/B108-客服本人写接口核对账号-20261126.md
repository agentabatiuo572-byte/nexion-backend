# B108 客服本人写接口核对账号

客服在确认页看到账号 A 后，另一标签页切换到账号 B 时，原操作必须停在后端。适用以下本人写接口。

| 接口 | 操作 |
| --- | --- |
| `POST /api/admin/content/support-agents/self/invite-code` | 生成或重置邀请码 |
| `POST /api/admin/platform/accounts/self/avatar-assets/default` | 准备默认头像 |
| `POST /api/admin/platform/accounts/self/avatar-assets` | 上传头像 |
| `PATCH /api/admin/platform/accounts/self/avatar` | 保存头像 |
| `DELETE /api/admin/platform/accounts/self/avatar-assets/{id}` | 取消头像素材 |

客户端可在 `X-Expected-Admin-Id` 传入确认页账号的管理员编号，格式为无前导零的正整数十进制。后端使用该请求已认证的管理员身份核对。请求头为空、格式无效、重复提供，或编号与当前管理员不同，返回 HTTP 409 和 `SELF_ACCOUNT_MISMATCH`。校验在调用写入服务和处理命令号前完成，因此拒绝不会变更邀请码、头像素材或账号，也不会写入或返回该命令的成功回执。

请求未携带该头时兼容旧客户端。账号一致的请求继续走原有客服资格、版本、素材归属和命令号规则。管理员代办和读取接口沿用各自规则。

对应业务规则为 OP-123、ST-27 和 ST-47。[原后端待办](https://github.com/agentabatiuo572-byte/uvel-docs/commit/e0043bc389a2ec53370d784cdc71aaf32520abaf)
