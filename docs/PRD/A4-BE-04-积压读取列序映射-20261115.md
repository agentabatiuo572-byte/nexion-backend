```
            2026-11-15T16:23:01,2026-11-15T16:23:01,null,null,0)

```

MyBatis 3.5.16 走 `DefaultResultSetHandler.applyConstructorAutomapping` / `createByConstructorSignature`，按 SELECT 投影顺序匹配 canonical 构造参数。

当前 `A4OutboxDiagnosticsMapper.page` 的尾部投影顺序是：

```
... errorCode,
H3_USER_ID AS userId,              -- 第 9 列
UNRESOLVED AS auditLinkUnresolved  -- 第 10 列
```

而 canonical record 的尾部是：

```
..., String errorCode, boolean auditLinkUnresolved, Long userId
```

因此普通非 H3 行（如 `store.viewed`）第 9 列 `H3_USER_ID` 为 null，被传给 primitive `boolean auditLinkUnresolved`，构造失败并 500；第 10 列 `UNRESOLVED` 的 0 反而落在 `Long userId`。H3 行则会把真实 userId 传给 boolean，同样错位（即使不抛异常也会语义错误）。

小6的列序定位与真实日志、当前源码一致；不是 SQL 数据/权限/查询异常。

## 2. 最小修复

只交换 `page` 的两列投影，使其与 canonical record 完全一致：

```sql
... errorCode,
UNRESOLVED AS auditLinkUnresolved,
H3_USER_ID AS userId
FROM nx_event_outbox o WHERE ...
```

对应 Java：

```java
+ UNRESOLVED + " AS auditLinkUnresolved, "
+ H3_USER_ID + " AS userId FROM nx_event_outbox o WHERE " + BACKLOG
```

- 只改 `A4OutboxDiagnosticsMapper.page` 的 SELECT 顺序；不新增列、不改表达式、不改查询、不新增 DTO/端点/容错层。
- 不改 `EventRow` record，不用 `userId=0`、不把 boolean 改 nullable、不靠 null 兜底掩盖错位。
- 行/汇总/分组/receipts 的字段含义不变；`unresolvedOnly` 过滤条件不变。

## 3. 修复后列序矩阵

`EventRow` canonical 构造：`(long id, String eventId, String eventType, String status, int retryCount, LocalDateTime createdAt, LocalDateTime nextRetryAt, String errorCode, boolean auditLinkUnresolved, Long userId)`

| SELECT 列 | 类型 | record 参数 |
|---|---|---|
| `o.id` | long | id |
| `o.event_id AS eventId` | String | eventId |
| `SAFE_TYPE AS eventType` | String | eventType |
| `SAFE_STATUS AS status` | String | status |
| `o.retry_count AS retryCount` | int | retryCount |
| `o.created_at AS createdAt` | LocalDateTime | createdAt |
| `o.next_retry_at AS nextRetryAt` | LocalDateTime | nextRetryAt |
| `errorCode` | String | errorCode |
| `UNRESOLVED AS auditLinkUnresolved` | boolean | auditLinkUnresolved |
| `H3_USER_ID AS userId` | Long/null | userId |

- 普通非 H3：`auditLinkUnresolved` 为 0/1 布尔，`userId=null`，不再把 null 传给 primitive。
- H3 五类且 canonical payload：`auditLinkUnresolved` 布尔，`userId` 为真实 Long；不再串位。
- H3 但 payload 不合法/非 authority：`userId=null`，不推断。
