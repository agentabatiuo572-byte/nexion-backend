# F5 奖励动作复核门禁

冻结、解冻、提前解锁、结算发放及驳回状态转换须经 A2 审批。持有相应 F5 动作权限的管理员直接调用奖励状态接口时，返回 `409 A2_CONFIRMATION_REQUIRED`；缺少对应动作权限时返回 403。审批回放仍核对当前版本和合法状态，再写入奖励、账本和审计。

现有 F5 动作权限允许发起相应的 F5 提案，并按原键找回本人的工单及当前状态。其他账号的键返回 404。发起者仍须通过准确的动作、对象和锁目标校验；A2 总览、日志和批准权限沿用原规则。

奖励状态使用专用 A2 指令和奖励记录锁。通用团队界面配置指令不能变更奖励状态。此前通过通用指令发起的待审工单可驳回。
