# B30 角色授权收回与岗位分权

BE-01 按 B30 交接的「角色授权清单」逐条收回内置角色的权限和菜单。迁移使用角色码和权限码定位绑定，待定权限及本批之外的绑定照旧。前向迁移放在启动链最后，防止历史种子重建已收回的绑定。角色、账号角色关系和自定义角色授权继续由 A1 管理。

财务与财务主管保留发起 A2 提案的权限。缺少该绑定的既有环境按批准清单补齐。A2 读权收回后，通过本人原请求键核对已有提案。财务主管保留清单内的专属权限，避免普通财务权限收回后影响主管的种子继承。

BE-02 向增长运营显式授予 D10 的七个权限。可查看活动、编辑草稿、查看编辑所需的政策、试算、提交并查看奖励和报表。审批、发布、停启、结案、重发、冲正和报表导出不随这七项授予。

BE-03 将脱敏用户清单导出授权给超管、审计和增长。风控继续使用原权限审核、拒绝、完成或取消账户注销。增长和审计收回该注销操作权限。导出继续写入原 C1 审计事件，缺失的事件登记在迁移中补齐。

BE-05 同步内置角色备注。配置运营显示「查看运营总览的部分页面」，只读审计显示「全域只读，可导出脱敏文件」。新库与既有库使用同一说明，角色授权和菜单绑定继续按已批准清单生效。

BE-43 为财务主管开放 E4 订单菜单、读取和退款权限。增长继续查看订单，收回退款权限。退款走既有业务校验和审批。

BE-46 移除风控、审计的 M3 专属会话菜单绑定。M3 既有业务权限按清单保留。
