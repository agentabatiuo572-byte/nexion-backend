# A1 账号提案逐动作授权

A2 提交 A1 账号提案时，发起人须具备 `platform_a2_proposal_create` 或 `platform_a2_write`，并持有对应的 A1 动作权限。

| 动作 | 回放命令 | A1 动作权限 |
| --- | --- | --- |
| 编辑资料 | `a1_account_update_profile` | `platform_a1_write` |
| 改角色 | `a1_account_change_role` | `platform_a1_account_role_change` |
| 重置两步验证 | `a1_account_reset_2fa` | `platform_a1_account_2fa_reset` |
| 启用或禁用账号 | `a1_account_status_update` | `platform_a1_account_disable` |

提案锁定命令中的目标账号，委托发起的审批摘要取自回放命令。批准人须为另一位具备 `platform_a2_operation_approve` 和对应动作权限的超级管理员。执行时继续校验账号版本、双超管下限及恢复模式限制，执行失败的提案仍待处理。

当前 PC 页面的四类发起入口仍要求 `platform_a2_write` 及对应动作权限。上述授权契约适用于 Java A2 提案接口。
