# B120 待处理风险分类与评分档位

运营后台可通过 `GET /api/admin/treasury/b-domain?riskFeed=OPEN_BY_CATEGORY` 读取 `riskRadar.feed` 的待处理风险口径。该请求需要 `overview_b1_read` 和 `overview_b5_read`。未传该参数时仍返回现有 B 线概览，供当前首页和消息铃铛继续使用。PC 要显示新统计时主动传此参数，并用各条目的筛选字段打开对应名单。

## 待处理信号

只统计按入库时间落在最近 7×24 小时内、处置进度为 `open` 的信号。尚无处置记录也算待处理。每个有待处理信号的类别返回一条，带 `category`、`categoryName`、`count`、`accountCount`、最高级别 `sev`、`latestAt`、`startAt`、`endAt` 和 `handlingStatus=open`。三个时间字段均为带偏移的 ISO 8601。处置后的信号退出统计，且不会抬高本类最高级别。

类别键为 `MULTI_ACCOUNT`、`ABUSE`、`WITHDRAW`、`TAMPER`、`USER_FROZEN`、`CHARGEBACK_SHORTFALL`、`OTHER`。余类 `OTHER` 覆盖其他所有信号。用 `GET /api/admin/risk/radar/signals` 的同一 `startAt`、`endAt`、`category` 和 `handlingStatus=open` 读取对应的信号数与去重账户数。列表支持重复或逗号分隔的类别，也可与原始 `signalType` 共同筛选。列表和详情返回同一分类键和中文名。

## 风险评分

新口径的评分条目每个非空档各有一行。有效分与既有名单一致，计入生效中的人工改分。

| `band` | 范围 |
| --- | --- |
| `AUTO_REPORT` | 有效分达到自动升级线 |
| `HIGH_BELOW_AUTO` | 有效分达到高风险线且低于自动升级线 |
| `MEDIUM` | 有效分达到中风险线且低于高风险线 |
| `STALE` | 按现有规则待首次评分或重新评分 |

使用 `GET /api/admin/risk/scoring/accounts?band=...` 核对名单人数。原 `HIGH` 接口和概览分布继续包含自动升级账户。缺少可用模型时，保留评分暂不可用提示。管理端接入与实景验证按页面变更流程执行。
