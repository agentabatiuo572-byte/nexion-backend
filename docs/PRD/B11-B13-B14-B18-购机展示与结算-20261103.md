# 复购活动、试用转购和购买回执

产品依据为 2026-10-28 交接的 20 号文档 B11、B13、B14、B18，以及正式 App P-58、P-59 和后台 H2 的协议。

## 复购活动

公开活动列表和详情均返回已发布版本的人群间隔 `repurchaseWindow.minDays/maxDays`。任一端点可为空。登录用户的 `lastValidPurchaseAt` 使用与资格预估相同的最近有效购机时间，格式为 UTC RFC 3339。匿名、没有有效订单或其他模板均不披露用户时间。取消和已退款订单排除在外。其他模板的 `repurchaseWindow` 为 null。

## H2 领取和转购

`trialOffsetCapUSD` 缺省或清空表示不设上限。H2 可设置 0 至 1,000,000，0 表示不使用收益抵扣。领取时将上限写入 `nx_trial_claim.offset_cap_usdt`，新单的 SQL NULL 表示不设上限，历史数值随原单保留。H2 读写使用空字符串表示留空，App 配置和报价使用 JSON null。更新时可回传读到的 `expectedValue`，发生冲突返回 409。15% 试用折扣及其单独封顶仍取原配置。

在原试用期内且早购优惠启用时，USDT 和 UVT 总权益按原期限结算。抵扣金取当前已产出的 USDT，并受领取时的上限和扣除通用试用折扣后剩余商品金额约束。固定早购立减最多抵到剩余应付金额。满期 USDT 减去实际抵扣的部分及全部 UVT 在同一笔转购成功后入钱包，按原奖励来源记账。宽限期使用实际满期收益。取消、超窗或付款失败不发奖励。

钱包转购重算服务器当前产出。仅随时间增长的抵扣不要求重新确认。规则切换或新金额高于确认的金额时重取报价。已签发的外部付款单按签发时间和当时规则核价，旧版在途付款单继续履行原报价。成功订单、实际抵扣和购后入账各有独立快照。退款按商品实付退回，奖励追索继续定位本单入账记录并仅追回可证明未花用的金额。

## 订单实付

App 订单列表和详情共用 `GET /api/orders` 的订单投影。普通、组合及活动订单的 `paidTotalUsdt` 为两位小数字符串。钱包实付等于商品订单金额，银行卡、BEP20、ERC20 使用本订单已交付付款单的 `quote_json.totalUsdt`，包含通道费和网络确认费。未付款为 null，缺乏支付凭据的历史记录保留 null。外部交付回执和旧回执重读返回同一金额。退款后仍可查询原实付，退款金额继续由原字段说明。商品金额 `amountUsdt` 和付款小计字段维持原语义。
