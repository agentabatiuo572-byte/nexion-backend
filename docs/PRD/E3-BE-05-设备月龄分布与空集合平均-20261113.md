## 1. 背景与当前事实

- E3 设备使用概览 `GET /api/admin/devices/e3/tradein/overview` 目前只返回：
  - `averageAgeMonths`：在用设备的平均月龄；
  - `cliffDeviceCount`：进入后期（`stageMidEnd + 1` 月起）的台数。
- 当前 SQL（`DeviceOpsMapper.tradeinOverviewMetrics`）使用
  `COALESCE(AVG(TIMESTAMPDIFF(MONTH, COALESCE(d.purchased_at, d.activated_at, d.created_at), NOW())), 0)`，
  没有在用设备时把平均月龄强制成 `0`；页面上的 `0.0` 无法区分“全是 0 月新设备”和“没有在用设备”。
- 同一查询没有早/中/后期台数；PC 只能用平均值和后期台数，画不出月龄分布。
- 原始待办见 `uvel-docs` `origin/main` 9c9830d `20-backend-pending-20261031.md:1437` E3-BE-05；旧事实基于 `66ecdb47`，当前 `df086fa8` 该查询仍未提供分布。

## 2. 既有在用集合、月龄公式与阈值（不新增）

### 2.1 在用集合

当前查询的 `WHERE` 即既有定义，本候选原样复用：

```sql
d.is_deleted = 0
AND d.status NOT IN ('RECYCLED','DEACTIVATED','INACTIVE','RETIRED')
```

平均月龄、早/中/后期台数全部使用同一集合；不新增状态、不排除其它状态、不改设备生命周期。

### 2.2 月龄公式与精度、时区

```sql
TIMESTAMPDIFF(MONTH,
  COALESCE(d.purchased_at, d.activated_at, d.created_at),
  NOW())
```

- 与现有平均月龄公式完全相同：优先 `purchased_at`，其次 `activated_at`，再次 `created_at`。
- 整数月；数据库 `NOW()` 的会话时区即当前口径，不新增全局时区或业务时区转换。
- 平均月龄由 MySQL `AVG` 返回，服务端不再四舍五入；PC 现有展示保留 1 位小数，本候选不改。
- 分布台数为整数计数。

### 2.3 既有阶段阈值

使用现有 E3 配置，不发明新阈值：

| 配置 | 默认 | 含义 |
|---|---|---|
| `stageEarlyEnd` | 3 | 前期截止月 |
| `stageMidEnd` | 8 | 中期截止月；后期从 `stageMidEnd + 1` 月起 |

现有 E3 配置写入校验要求 `stageEarlyEnd < stageMidEnd < cycleMonths`；本候选不修改配置、不新增校验或 fallback。

分桶：

- `earlyDeviceCount`：`ageMonths <= stageEarlyEnd`（含 0 月新设备）；
- `midDeviceCount`：`stageEarlyEnd < ageMonths <= stageMidEnd`；
- `cliffDeviceCount`：`ageMonths > stageMidEnd`，与既有“后期/第 `stageMidEnd+1` 月起”一致，沿用原字段名。

三桶互斥，正常配置下合计等于同一批在用设备数。

`DeviceTradeinOverviewView` 在原有字段中增加两个计数，放在 `cliffDeviceCount` 之后；原字段名称和值不变，新增字段为增量：

```json

  "cliffDeviceCount": 2,
  "earlyDeviceCount": 7,
  "midDeviceCount": 3,
  "tradeinMonthCount": 0,
```

- `averageAgeMonths`：
  - 有在用设备：真实 `AVG`，可以为 `0`（全是 0 月设备）；

- `earlyDeviceCount`/`midDeviceCount`/`cliffDeviceCount`：
  - 无在用设备：全部 `0`；
  - 有设备：按 §2.3 同一集合、同一公式计数。
- 既有字段 `cliffDeviceCount` 的含义保持“后期台数”，不新增 `lateDeviceCount`、不增加兼容字段/default 0。
- 新增字段为向后兼容增量；不改接口路径、权限、审计、E3 参数或其它 overview 字段。

## 5. 实现点

| 文件 | 变更 |
|---|---|
| `device/mapper/DeviceOpsMapper.java` | 用同一在用集合/月龄公式的子查询计算 `AVG`、早/中/后期三桶；平均不再 `COALESCE`；`TradeinOverviewMetrics` 增加 `earlyDeviceCount`/`midDeviceCount` |
| `device/domain/DeviceTradeinOverviewView.java` | 增加 `earlyDeviceCount`、`midDeviceCount` 两个字段 |
| `device/domain/DeviceOpsRepository.java` | `e3TradeinOverview` 参数由 `cliffMonth` 改为 `earlyEnd, midEnd` |
| `device/infrastructure/MybatisDeviceOpsRepository.java` | 传两个阈值并映射新增计数 |
| `device/application/OpsDeviceService.java` | 读取现有 `stageEarlyEnd`/`stageMidEnd`，不新增阈值/默认 |

SQL 形状：

```sql
SELECT AVG(ageMonths) AS averageAgeMonths,
       COALESCE(SUM(CASE WHEN ageMonths > #{midEnd} THEN 1 ELSE 0 END), 0) AS cliffDeviceCount,
       COALESCE(SUM(CASE WHEN ageMonths <= #{earlyEnd} THEN 1 ELSE 0 END), 0) AS earlyDeviceCount,
       COALESCE(SUM(CASE WHEN ageMonths > #{earlyEnd} AND ageMonths <= #{midEnd} THEN 1 ELSE 0 END), 0) AS midDeviceCount
  FROM (
      SELECT TIMESTAMPDIFF(MONTH, COALESCE(d.purchased_at, d.activated_at, d.created_at), NOW()) AS ageMonths
        FROM nx_user_device d
       WHERE d.is_deleted = 0
         AND d.status NOT IN ('RECYCLED','DEACTIVATED','INACTIVE','RETIRED')
  ) device_age
```

- 子查询保证平均和三桶使用同一批行、同一月龄表达式；不写静态样例、不造设备。
- 无行时 `AVG` 为 null，三个 `SUM` 经 `COALESCE` 为 0。
- 有 0 月设备时 `AVG=0`，`earlyDeviceCount` 包含它们；与无设备的 null 区分。
