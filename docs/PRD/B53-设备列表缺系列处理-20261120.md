# B53-BE-08 设备列表缺系列处理

设备缺系列且无法按设备类型分类时，设备列表接口跳过该条记录，照常返回同账号的正常设备。缺失记录不参与列表收益汇总，设备实际占用的名额仍按原规则计算。手机和 PC GPU 原有分类继续有效。其它设备校验错误仍按原规则处理。

账号只有缺系列且占名额的设备时，后端返回空列表和实际名额。当前共享 TEST App 对该结果的解析仍有限制。本轮按后端接口验收此边界。

| 场景 | 业务验收 |
| --- | --- |
| 同账号同时有正常设备和缺系列的实物设备 | 经真实 App 登录请求 `GET /api/devices/earnings`，接口返回成功，正常设备的分类、容量和收益仍可读，缺系列的临时设备不返回，不进入收益汇总。 |
| 账号只有缺系列的实物设备 | 返回成功与空设备列表。已有钱包和名额字段仍可读。 |
| 复核原有设备 | 对照临时异常设备加入前后的正常设备，核对列表主要字段。读取首页总览接口，核对仍能成功返回。清理临时设备后复查列表。 |
