# BE-27 F4 榜单取消资格的风险证据

依据 B30 第 27 项、S06 与 F-PD06。

取消成员本周榜单资格需要该成员有本业务周内由 K2 服务产生的有效刷榜信号，或在有效 K1 簇中以实际成员身份命中。通用风控手工信号使用独立编号，即使名称相同也不能作为 K2 依据。K1 簇的待处理、已标记及已冻结状态可作为依据。已解除、已清除或已删除的簇不作为依据。K2 信号按 GROWTH_TEAM 业务周计算，包含周初，截止于下一周周初之前。

A2 发起和实际处置时都核验证据。无证据返回 HTTP 422 `NO_RISK_EVIDENCE`，不会取消资格。审批前证据已失效时，原申请保持待审。直接通过原 F4 配置接口发起的同一成员处置也受证据检查。成功处置的审计包含实际使用的 K1 簇编号或 K2 信号编号。

区域大使审批的材料核验门槛待明确权威数据来源和操作入口。申请单目前只记录 App 提交内容、审批状态和开通预算。需明确线下签到真实性与人数、KOL 发票及流量的独立核验结果，以及物料和 SDK 配额如何映射到现行预算类别与申请号。材料核验应是独立于大使批准和 A2 决策的持久状态，本次维持现有批准与拒绝流程。
