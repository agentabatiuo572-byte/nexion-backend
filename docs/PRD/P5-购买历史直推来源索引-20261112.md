## 最小变化与业务边界

新增完整、非唯一、可见 BTREE 索引 `idx_direct_source_ref_type(source_ref,source_type)`。`source_ref` 保持原 `VARCHAR(96)/utf8mb4_bin`，`source_type` 保持原 `VARCHAR(32)/utf8mb4_0900_ai_ci`；不改变列、字符集、排序规则、唯一约束或已有索引。

原 COUNT SQL 和历史模式判断完整保留，不补环境、run_id、删除标记或其他过滤，不加入 Java hint。索引覆盖原查询所需两列，使优化器可以按来源定位；不把跨环境或矛盾历史行排除。保留所有管理员修改、发布、暂停、版本锁，买家/订单/钱包锁，金额与600秒规则，拒绝行、WAITING 恢复、事件重投及退款幂等。本批无 Java 改动，不改鉴权、调度、超时或容量判据。

## 迁移与回退

迁移文件为 `scripts/migrations/20261112_direct_referral_source_history_index.sql`；沿既有 earnings 来源索引方式，在不存在时以 `ALGORITHM=INPLACE, LOCK=NONE` 添加，存在时不重建。随后严格检查两列顺序、非唯一、完整列、可见 BTREE 和 ASC；同名错误形状明确失败，不自动替换。

PowerShell 启动清单在 direct bootstrap 和 seven-layer split 后登记新迁移，保留旧建表迁移字节。DDL 会隐式提交并产生一次索引构建与空间开销；私库由主线程在 App 停止后执行，实际耗时和空间以回执为准。必要回退仅删除本批新增索引：

```sql
ALTER TABLE nx_direct_referral_settlement
DROP INDEX idx_direct_source_ref_type, ALGORITHM=INPLACE, LOCK=NONE;
```
