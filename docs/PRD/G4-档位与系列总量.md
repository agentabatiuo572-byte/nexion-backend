# G4 档位与系列总量

追加档位或修改末档截止时，已有唯一在售系列的总供应量随末档截止一同更新。档位、系列总量、档位版本和审计共用同一事务。总量变更沿用 `finprod_g4_write` 与供给字段的既有操作锁，增加总量需通过 B1 覆盖率红线检查。审计记载总量调整前后的值。

联动写入的总量不得低于已售，也不得超过既有上限 100,000。修改非末档时只调整相邻边界，末档和总量保持原值。没有在售系列时可以准备档位，由既有初始化命令以末档截止创建系列。目录保留连续性、已售和末档与总量相等的读取检查。

独立的「节点总量」命令同样一次更新系列总量和末档截止，保留档位起点、价格与历史订单及持仓。目标总量必须大于末档起点，避免覆盖其他档位。越过该边界时，命令拒绝变更并返回 `GENESIS_SUPPLY_REQUIRES_TIER_UPDATE`，由档位命令处理区间调整。

独立调整沿用同一权限、操作锁、已售下限、100,000 上限和扩容覆盖率检查。末档截止变化时递增档位版本。审计记载末档、总量与版本的前后值。以同一幂等键重放成功请求时返回既有结果。
