# H2 试用经营统计口径

`GET /api/admin/growth/trials` 的经营统计覆盖正式试用库中仍保留的全部账号。每个账号以最近一次已开始的试用为准，同一账号重领后沿用该账号的当前记录。列表分页不会改变这个统计范围。

- `trialBuyRate` 是已转购账号数除以已开始试用的账号数。转购取试用生命周期的 `REDEEMED` 终态。
- `earlyBuyRate` 是按全期权益规则完成提前转购的账号数除以同一批已开始试用的账号数。分类取转购结算快照。若现存的已转购记录中有无法分类的历史记录，返回 `null`。
- 当前试用领取已移除绑卡环节，旧绑卡转化指标停止计算。保留 `bindCardRate` 字段以兼容现有客户端，固定返回 `null` 表示不可计算。
- `k2Blocked` 按试用入口现有规则统计带有未删除 `risk.trial_cycle_detected` 信号的去重账号数。多个同类信号只计一人。该值表示当前受拦截规则覆盖的人数。

两个比率按百分数返回，无分母时为 `null`，分母大于零且无人转化时为 `0%`。统计数据源不可用时，列表读取返回 `503 TRIAL_STATS_UNAVAILABLE`。活动、试用中、宽限和延长沿用现有计数规则。
