# H3、H4、H5 退役入口与检查间隔

- H3 旧月度挑战新建返回 `H3_MONTHLY_CREATION_RETIRED`。质押和创世认购从可新选任务路由移除，现有任务保留状态与原路由，可在不改变原路由时编辑其他允许字段。
- H4 转盘新建或编辑拒绝新增积分类型。历史积分档可查，编辑、删除和修改概率返回 `WHEEL_POINTS_TIER_RETIRED`。调其他档位时积分档继续参与总概率校验，原值保留。
- H5 连签成长奖励所指的业务已停用时，单字段、整体配置及 A2 放宽提案均拒绝写入。收益里程碑检查间隔由持有 `growth_h5_tick_write` 的超级管理员调整。

## 2026-11-16 补充：三条退役的周质押任务与新手上手组

本文开头已废止「质押和创世认购作为可新选任务路由」，但三个已经存在的周任务仍停在暂停态、可被运营再次启用：`weekly_t1_nex_v2_lock`、`weekly_t1_stake_fallback`、`weekly_t2_stake_small`。此前它们只能被「周任务缺少可信完成事实」这条**功能性**校验挡住（`H3_MISSION_VERIFIED_COMPLETION_UNAVAILABLE`），一旦该前提被别的改动放宽，就会重新开卖。

现按退役处理：

- 三个任务码在启用（`expected=paused → target=enabled`）时直接返回 `H3_MISSION_RETIRED`，先于其它启用前置校验；原有的绑定/完成事实/业务可用性校验保留不变，其它任务行为不变。
- 新手上手组（`mission_type = DAY_ONE`）新建任务时，若任务码命中**本服务已经在用的**质押信号（`stake` 或 `lock`，与启用路径同一判断，不新增类型字段或模糊匹配），返回 `H3_DAY_ONE_STAKING_MISSION_REFUSED`。
- 不改任何数据：这三条记录的现有状态、奖励、绑定与历史领奖不变；不新增表/列、不迁移、不回填；其它任务、G1 质押退役政策、奖励口径、任务编辑与归档流程均未改。

任务码的退役集合与 DAY_ONE 质押信号只在比较前转为 ROOT 小写，以对齐现有不区分大小写的仓储匹配；不改传入命令、摘要、存储值、历史行或其它任务的功能性校验。
