# H3、H4、H5 退役入口与检查间隔

- H3 旧月度挑战新建返回 `H3_MONTHLY_CREATION_RETIRED`。质押和创世认购从可新选任务路由移除，现有任务保留状态与原路由，可在不改变原路由时编辑其他允许字段。
- H4 转盘新建或编辑拒绝新增积分类型。历史积分档可查，编辑、删除和修改概率返回 `WHEEL_POINTS_TIER_RETIRED`。调其他档位时积分档继续参与总概率校验，原值保留。
- H5 连签成长奖励所指的业务已停用时，单字段、整体配置及 A2 放宽提案均拒绝写入。收益里程碑检查间隔由持有 `growth_h5_tick_write` 的超级管理员调整。
