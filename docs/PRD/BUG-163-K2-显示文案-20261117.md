# BUG-163 K2 显示文案

2026-11-17。依据本轮已批准的四处显示方案，仅调整 K2 overview 的返回投影，不修改检测、数据库写入或前端实现。

## 显示合同

入口：`GET /api/admin/risk/arbitrage/overview`，沿用 `risk_k2_read` 权限。

| 区域 | 原显示 | 批准显示 |
| --- | --- | --- |
| `views[key=board].head[2]` | `增速(对基线)` | `奖励增长倍数` |
| `views[key=board].rows[].cells[2]` | 例如 `8.30x 基线` | `8.30 倍` |
| `params[key=leaderboardVelocityMultiplier].sub` | `佣金增速超过基线倍数时产生刷榜信号` | `奖励增长超过比较样本中位数的设定倍数时，产生刷榜风险信号。` |
| `views[key=board].note` | 保留原文 | 追加下列奖励增长倍数定义 |

board 读法完整返回：

> 这里只标记并发信号给「奖励池、名额与排行榜」和风险雷达。取消参榜资格和从奖池剔除在「奖励池、名额与排行榜」执行。奖励增长倍数＝该账户奖励增加额÷比较样本奖励增加额的中位数。比较样本取本周最近两次快照的正向增长记录，并排除已标记刷榜风险的账户。

## 输出与保留边界

- 仅在 `OpsRiskService.arbitrageOverview()` 组装显示响应时，对 `board` 的第三个单元格转换。整个单元格必须匹配“非负整数或小数 + `x 基线`”，数值文本直接保留，例：`8.30x 基线` → `8.30 倍`、`12x 基线` → `12 倍`，不解析数值、不重新舍入或增减小数位。
- 已为 `8.30 倍` 的文本、其他自定义文本、不符合上述完整格式的文本原样返回。`board` 其他单元格以及 `trial`、`tradein`、`gift` 的全部单元格不转换；不足三个单元格的行原样返回。
- 行的 `rowId`、`viewKey`、`clusterId`、`level`、`actions`、`disposition`、`version`、`clusterStatus`、`clusterVersion` 保留原值。统计使用原始行；显示副本不进入检测、信号生成、处置或审计快照。
- 参数仅改 overview 中的 `sub`；`key`、`name`、`value`、`note`、`version` 原样保留，`> 5x 基线` 等值和既有解析词、调整与保存链路不变。参数存储、历史命中行及历史审计原文不迁移、不回填。
- `k2Views` 仅调整 board 的上述表头和读法。其他表头、页签、按钮、导航、可见范围及权限不变；PC 与其他前端代码不改，不接入私有 K1 实现。
