# B26 六种界面语言

中、英、越始终开启。运营还可以开启印尼语（id）、马来语（ms）、菲律宾语（fil）、俄语（ru）、哈萨克语（kk）和乌兹别克语（uz）。

| 入口 | 业务规则 |
|---|---|
| A3 应用体验配置 | 读写 `interfaceLanguages`。首次使用默认开启九种，按 zh、en、vi、id、ms、fil、ru、kk、uz 排列。关闭基础语言、重复代码或未知代码均拒绝。保存沿用 A3 的权限、版本、理由和审计。旧客户端省略此字段保存其他设置时沿用现值。 |
| App 与 H5 Lite | 公共平台配置顶层返回同一列表。端上已安装的界面词典与账户偏好分别管理。关闭某种语言后，客户端下次成功取得配置时隐藏该语言，当前使用者改用英文。重新开启后该语言重新可选。 |
| 账号 | 既有受支持手机号的注册及资料更新均接受九种代码。资料读取返回保存的语言，地区标记归一到基础代码。客户端发送 `ru` 时，其他设备登录同一账号可读回 `ru`。 |
| 运营内容 | 活动、任务、促销、FAQ、课程、玩法、段位、开发者文档、信任中心、风险提示书、条款、隐私及抽奖通过各自的发布流程维护译文。同一版本已有目标语时使用译文，缺少译文时使用该版本的英文。历史确认与不可变快照继续按原版本读取。 |
| 消息 | 站内通知、推送和短信在交付时按账户语言解析模板，缺项取英文。已投递通知保留其实际文案。 |
| 文案包、实验和统计 | 运行时文案包支持六种新增语言并逐键使用已发布的英文后备。文案实验可按九种语言圈选受众，BI 按有来源的注册语言过滤和分组。 |

英文 FAQ 的运营接口可以用 `translations.ru.question` 和 `translations.ru.answer` 等字段维护同一条目的翻译。列表按条目和当前发布版本选择语言，译文缺失的条目继续显示英文。省略 `translations` 保留现有翻译，空对象清除。原有单独发布的语言条目保留各自的 ID。

首日任务在注册时冻结该版本的任务名和可用译文。缺少目标译文时读取同一快照的英文。老任务若只留下无语言标记的原始任务名，返回原值并用 `nameLocale=und` 标识，不按后来的任务配置改写历史。

本批交付后端。现有 App 和 H5 Lite 将新增语言的注册和资料写入映射成 `en`，相关运营内容读取也请求英文，运行时文案包只请求原三语。前端选俄语并通过现有接口保存时，另一安装读取的账户值是 `en`。账户接口与现有客户端分别验收。手机号地区范围沿用现行规则。
