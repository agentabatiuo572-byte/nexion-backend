# B26 六种界面语言

只有英文（en）始终开启。中文（zh）、越南语（vi）、印尼语（id）、马来语（ms）、菲律宾语（fil）、俄语（ru）、哈萨克语（kk）和乌兹别克语（uz）均由运营开关。内容存储的中、英、越三语分组不变。

| 入口 | 业务规则 |
|---|---|
| A3 应用体验配置 | 读写 `interfaceLanguages`。没有 active 配置时默认开启除中文外的八种：en、vi、id、ms、fil、ru、kk、uz。配置输出按 zh、en、vi、id、ms、fil、ru、kk、uz 的顺序排列。仅英文不可关闭；缺少 en、重复代码、未知代码或非数组均拒绝。保存沿用 A3 的权限、版本、理由、审计和幂等规则。旧客户端省略此字段保存其他设置时沿用现值，不覆盖运营已有配置。 |
| A3 运营区域语言 | 管理端 `GET/PUT /api/admin/platform/config/experience` 读写 `operatingLanguages`，沿用 A3 的权限、版本、理由、审计和幂等规则；更新省略此字段时保留现值，从未保存时为 `["en"]`。必须包含 `en`，可选 `zh`、`vi`，按 en、zh、vi 顺序返回。缺少 en、重复代码、非数组或其他值（含新增六语）返回 `422 PLATFORM_OPERATING_LANGUAGES_INVALID`。任何已登录运营账号可通过 `GET /api/admin/platform/config/operating-languages` 读取，响应 `data` 为 `{ "operatingLanguages": [...] }`；此字段不进入 App 公共平台配置。 |
| App 与 H5 Lite | 公共平台配置顶层返回同一列表。端上已安装的界面词典与账户偏好分别管理。关闭某种语言后，客户端下次成功取得配置时隐藏该语言；当前使用者依次改用自己明确选过的、账号的或系统（浏览器）的已开启语言，都没有时用英文。自动切换不写回账号。重新开启后该语言重新可选，用户原先明确选择的语言恢复生效。 |
| 账号 | 既有受支持手机号的注册及资料更新均接受九种代码，未知代码仍返回 422。合法但当前已关闭的语言保存为 `en`；已开启的语言（包括 `ru` 等新增六语）照存。手机注册在创建账号前确定有效语言，数据库、欢迎语入参和注册事件 locale 使用同一有效值；未传语言时沿用 `en-US` 存储约定，OAuth 新账号仍为 `en-US`，App 与 H5 Lite 在第三方登录新建账号后按当时显示的界面语言写一次资料语言。App 与 H5 Lite 注册和更新资料语言时发送真实的界面语言代码（不再把新增六语换成 en）。资料更新的写库、审计和响应都使用有效保存值。资料读取不因开关改写账号，仍返回保存的语言并把地区标记归一到基础代码。 |
| 运营内容 | 支持读取回退的入口按发布版本优先取目标语，缺少时取同版本英文，英文也缺少时不展示。I4 信任版块的 App 读取已有本地化字段族时，若缺少所请求语言，该字段不展示。中文请求沿用各入口的中文读取规则。运营内容的多语写入只强制填写英文和已选的运营区域语言：运营后台，以及 I4、I5、I2、I3、M5、A3 的后端保存入口，在保存时用英文补齐整组留空的选填中文或越南语，部分填写仍须补齐。已启用的存量活动不追溯修改，缺英文的存量任务继续显示原名。历史确认与不可变快照继续按原版本读取，已投递消息保留原文。 |
| H4 活动、商城促销、创世抽奖 | 正式保存要求英文和运营区域语言，未选中的中文或越南语整组为空时复制英文，部分填写时拒绝。活动草稿按单格保存，直接进入进行中时补齐，需审批的开启提案会保存并绑定三语文案。普通促销草稿保留原语言键和值，送审时补齐并冻结合同。政策在创建不可变版本时补齐。创世抽奖在保存草稿或创建开启提案时补齐。 |
| 消息 | 站内通知、推送和短信在交付时按账户语言解析模板标题和正文，缺项取英文。CTA 可能是单份原文。已投递通知保留其实际文案。 |
| 文案包、实验和统计 | 后端运行时文案包支持六种新增语言并逐键使用已发布的英文后备。文案实验可按九种语言圈选受众，BI 按有来源的注册语言过滤和分组。 |

任一已存语言清单无效时，A3 管理体验配置读取将该字段返回为 `null`。提交对应字段的合法清单即可恢复，恢复审计将原值标为 `<invalid>`。省略仍无效的字段，以及通过独立运营区域语言接口或 App 读取其依赖的无效清单时，返回原有的 503 错误。

FAQ 越南语请求按同一入口和分类读取已发布条目。该范围内没有越南语条目时，读取英文条目。英文请求直接读取英文条目，缺少时返回空列表。直接请求新增六语之一时，后端读取目标语独立条目及英文条目，英文条目有目标译文时使用译文。英文 FAQ 的运营接口可用 `translations.ru.question` 和 `translations.ru.answer` 等字段维护同一条目的翻译。省略 `translations` 保留现有翻译，空对象清除。独立发布的语言条目保留各自的 ID。

首日任务在注册时冻结该版本的任务名和可用译文。缺少目标译文时读取同一快照的英文。老任务若只留下无语言标记的原始任务名，返回原值并用 `nameLocale=und` 标识，不按后来的任务配置改写历史。

英文、越南语或新增六语请求若在按现有语言规则和英文回退后仍无法读到课程标题、正文或完整测验，该课不进入列表，详情和开始接口返回 `LEARNING_COURSE_UNAVAILABLE`。没有测验题的历史阅读课（旧数据，新发布已要求测验）照常展示，读完即完成；只有带题目的课程检查测验是否完整。已得奖励标题按其课程版本读取。非转盘活动列表和详情接口的 `rewardName` 以实际可发奖励为准。有规则的活动返回当前规则计算的奖励摘要；无规则的旧活动对正数 UVT/USDT 奖励显示实际金额和资产，已参与用户取自己的奖励快照，未参与用户取活动当前配置。转盘与其他无规则旧活动奖项仍按请求语言、英文、原始奖项名称回退。App/Lite 在活动列表卡片和列表内领取成功提示显示奖名，详情页不显示。此读取规则不改奖励明细、发放与发布语言校验。

本批后端交付覆盖 FAQ、课程和测验的读取回退及活动启用校验。App 和 H5 Lite 的运营内容接口仍按中、英、越三语读取，新增六语界面使用英文运营内容。运行时远端文案包仍只请求原三语。运营后台的译文编辑范围依内容类型而异，部分已发布的新增六语译文暂无法由上述客户端入口读取。手机号地区范围沿用现行规则。
## I4-BE-04 发布字段兼容（2026-11-16）

I4 创建和更新草稿时按版块检查各本地化字段族。英文和已选运营区域语言必填，未选语言整组留空时用英文填入各对应字段，任一字段有值时该语言整组必填。固定结构保留发布模板中已有基础语言键的拼写和共享键；旧单语文本字段的升级仍须提交三语。

新发布和回退使用已保存版本，仍检查每块 1–80 个字段、分段键名、标签、值类型及大小写不敏感去重。发布、回退和公开快照均要求各本地化字段族有英文。历史快照缺中文或越南语仍可读取，缺失字段沿用 App 的现有展示规则。合法原成功回执继续先恢复。

## I2、I3、M5 与 A3 内容写入（2026-11-18）

Nova 模板、站内信草稿和注册欢迎语保存时要求英文及已选的运营区域语言。选填中越译文整组留空时，后端保存对应英文副本。模板及站内信按标题和正文整组判断，填写其中一项就须填齐；变量按原字段规则与英文对齐。发布、排期和派发使用已存内容。A3 官方安装包说明支持中英两项，英文必填，中文未选为运营区域语言且留空时保存英文副本。同一次保存变更运营区域语言时使用本次提交的设置。
