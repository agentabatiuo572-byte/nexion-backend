# B26 六种界面语言

只有英文（en）始终开启。中文（zh）、越南语（vi）、印尼语（id）、马来语（ms）、菲律宾语（fil）、俄语（ru）、哈萨克语（kk）和乌兹别克语（uz）均由运营开关。内容存储的中、英、越三语分组不变。

| 入口 | 业务规则 |
|---|---|
| A3 应用体验配置 | 读写 `interfaceLanguages`。没有 active 配置时默认开启除中文外的八种：en、vi、id、ms、fil、ru、kk、uz。配置输出按 zh、en、vi、id、ms、fil、ru、kk、uz 的顺序排列。仅英文不可关闭；缺少 en、重复代码、未知代码或非数组均拒绝。保存沿用 A3 的权限、版本、理由、审计和幂等规则。旧客户端省略此字段保存其他设置时沿用现值，不覆盖运营已有配置。 |
| App 与 H5 Lite | 公共平台配置顶层返回同一列表。端上已安装的界面词典与账户偏好分别管理。关闭某种语言后，客户端下次成功取得配置时隐藏该语言；当前使用者依次改用自己明确选过的、账号的或系统（浏览器）的已开启语言，都没有时用英文。自动切换不写回账号。重新开启后该语言重新可选，用户原先明确选择的语言恢复生效。 |
| 账号 | 既有受支持手机号的注册及资料更新均接受九种代码，未知代码仍返回 422。合法但当前已关闭的语言保存为 `en`；已开启的语言（包括 `ru` 等新增六语）照存。手机注册在创建账号前确定有效语言，数据库、欢迎语入参和注册事件 locale 使用同一有效值；未传语言时沿用 `en-US` 存储约定，OAuth 新账号仍为 `en-US`。资料更新的写库、审计和响应都使用有效保存值。资料读取不因开关改写账号，仍返回保存的语言并把地区标记归一到基础代码。 |
| 运营内容 | 活动、任务、促销、FAQ、课程、玩法、段位、开发者文档、信任中心、风险提示书、条款、隐私及抽奖通过各自的发布流程维护译文。同一版本已有目标语时使用译文，缺少译文时使用该版本的英文。历史确认与不可变快照继续按原版本读取。 |
| 消息 | 站内通知、推送和短信在交付时按账户语言解析模板，缺项取英文。已投递通知保留其实际文案。 |
| 文案包、实验和统计 | 运行时文案包支持六种新增语言并逐键使用已发布的英文后备。文案实验可按九种语言圈选受众，BI 按有来源的注册语言过滤和分组。 |

英文 FAQ 的运营接口可以用 `translations.ru.question` 和 `translations.ru.answer` 等字段维护同一条目的翻译。列表按条目和当前发布版本选择语言，译文缺失的条目继续显示英文。省略 `translations` 保留现有翻译，空对象清除。原有单独发布的语言条目保留各自的 ID。

首日任务在注册时冻结该版本的任务名和可用译文。缺少目标译文时读取同一快照的英文。老任务若只留下无语言标记的原始任务名，返回原值并用 `nameLocale=und` 标识，不按后来的任务配置改写历史。

本批交付后端。现有 App 和 H5 Lite 将新增语言的注册和资料写入映射成 `en`，相关运营内容读取也请求英文，运行时文案包只请求原三语。前端选俄语并通过现有接口保存时，另一安装读取的账户值是 `en`。账户接口与现有客户端分别验收。手机号地区范围沿用现行规则。
