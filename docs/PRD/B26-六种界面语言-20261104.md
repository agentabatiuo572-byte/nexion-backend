# B26 六种界面语言

只有英文（en）始终开启。中文（zh）、越南语（vi）、印尼语（id）、马来语（ms）、菲律宾语（fil）、俄语（ru）、哈萨克语（kk）和乌兹别克语（uz）均由运营开关。内容存储的中、英、越三语分组不变。

| 入口 | 业务规则 |

| 消息 | 站内通知、推送和短信在交付时按账户语言解析模板标题和正文，缺项取英文。CTA 可能是单份原文。已投递通知保留其实际文案。 |
| 文案包、实验和统计 | 后端运行时文案包支持六种新增语言并逐键使用已发布的英文后备。文案实验可按九种语言圈选受众，BI 按有来源的注册语言过滤和分组。 |

I6 重扫优先检查已发布词条，将每份已填写的译文与英文比对占位符；I5 在创建地区映射生效的 A2 工单前检查目标版本是否已存齐英文。

任一已存语言清单无效时，A3 管理体验配置读取将该字段返回为 `null`。提交对应字段的合法清单即可恢复，恢复审计将原值标为 `<invalid>`。省略仍无效的字段，以及通过独立运营区域语言接口或 App 读取其依赖的无效清单时，返回原有的 503 错误。

FAQ 越南语请求按同一入口和分类读取已发布条目。该范围内没有越南语条目时，读取英文条目。英文请求直接读取英文条目，缺少时返回空列表。直接请求新增六语之一时，后端读取目标语独立条目及英文条目，英文条目有目标译文时使用译文。英文 FAQ 的运营接口可用 `translations.ru.question` 和 `translations.ru.answer` 等字段维护同一条目的翻译。省略 `translations` 保留现有翻译，空对象清除。独立发布的语言条目保留各自的 ID。

首日任务在注册时冻结该版本的任务名和可用译文。缺少目标译文时读取同一快照的英文。老任务若只留下无语言标记的原始任务名，返回原值并用 `nameLocale=und` 标识，不按后来的任务配置改写历史。

英文、越南语或新增六语请求若在按现有语言规则和英文回退后仍无法读到课程标题、正文或完整测验，该课不进入列表，详情和开始接口返回 `LEARNING_COURSE_UNAVAILABLE`。没有测验题的历史阅读课（旧数据，新发布已要求测验）照常展示，读完即完成；只有带题目的课程检查测验是否完整。已得奖励标题按其课程版本读取。

活动列表和详情接口的 `rewardName` 以实际可发奖励为准。有规则的非转盘活动显示规则计算的奖励摘要。无规则且发放正数 UVT 或 USDT 的旧活动显示实际金额和资产（接口 `rewardName` 只给资产，App 与 Lite 在前面拼上 `rewardAmount`；管理端 `appRewardNames` 同样将金额四舍五入并固定为两位小数再拼上资产），已参与用户取自己的奖励快照，未参与用户取活动当前配置。转盘和其余无规则旧活动使用运营奖名，按请求语言、英文、原始奖名回退。发布、开启及创建开启提案时，标题与说明按英文和运营区域语言校验，只有使用运营奖名的活动按同一语言要求校验奖名。App/Lite 在活动列表卡片和列表内领取成功提示显示奖名，详情页不显示。

H4 人工单格保存按读回原文区分大小写并逐字比对旧值，活动概览对包括无规则旧活动在内的每条活动返回实际发布门的文案缺项。规则就绪视图对已启用活动也使用同一文案检查，缺英文时列出缺项并保留启用状态。

本批后端交付覆盖 FAQ、课程和测验的读取回退及活动启用校验。App 和 H5 Lite 的运营内容接口仍按中、英、越三语读取，新增六语界面使用英文运营内容。运行时远端文案包仍只请求原三语。运营后台的译文编辑范围依内容类型而异，部分已发布的新增六语译文暂无法由上述客户端入口读取。手机号地区范围沿用现行规则。
## I4-BE-04 发布字段兼容（2026-11-16）

I4 创建和更新草稿时按版块检查各本地化字段族。英文和已选运营区域语言必填，未选语言整组留空时用英文填入各对应字段，任一字段有值时该语言整组必填，判空沿用 ECMAScript trim。固定结构保留发布模板中已有基础语言键的拼写和共享键。允许升级的旧单语文本字段在提交有效的 `.en` 文案后即可转为语言族，中越沿用草稿补齐规则。

新发布和回退使用已保存版本，仍检查每块 1–80 个字段、分段键名、标签、值类型及大小写不敏感去重。发布、回退和公开快照均要求各本地化字段族有英文。历史快照缺中文或越南语仍可读取，缺失字段沿用 App 的现有展示规则。合法原成功回执继续先恢复。

## I2、I3、M5 与 A3 内容写入（2026-11-18）

Nova 模板、站内信草稿和注册欢迎语保存时要求英文及已选的运营区域语言。选填中越译文整组留空时，后端保存对应英文副本。模板及站内信按标题和正文整组判断，填写其中一项就须填齐；变量按原字段规则与英文对齐。发布、排期和派发使用已存内容。A3 官方安装包说明支持中英两项，英文必填，中文未选为运营区域语言且留空时保存英文副本。同一次保存变更运营区域语言时使用本次提交的设置。

## 运营语言台账补充（2026-11-18）

- **I5 法律条款**：语言和法域各自独立发布、撤销及生效，不自动同步其它语言，也不阻止独立发布英文。读取依次尝试请求语言、基础语言、英文；对每个候选语言先查请求法域，再查 `GLOBAL`。页面须以响应的版本及实际语言、法域为准；签收校验当前解析出的版本。同法域已有越语 v8、仅发布英语 v9 时，越语请求仍读取并按 v8 签收，不把 v9 记为已确认。已有同版本签收的跨语言兼容逻辑不变。
- **I6 文案覆盖率**：I6/I7 合并总览新增 `publishedMessages`，按词条键提供独立的有效发布版本及其语言内容；没有发布版本的键不出现在映射中。`messages` 仍供编辑最新版本；计算上线覆盖率时只使用 `publishedMessages`，不能把草稿当作已发布译文。
- **M4 FAQ**：越语按入口和分类查已发布条目，仅当整个查询范围没有越语条目时才按相同范围回退至英文；有越语条目但缺某条英文问答时不单条补齐。中文请求不回退，新增六语的英文条目及同条英文记录的目标译文读取规则不变。独立条目没有跨语关联，不按标题或排序猜配对。
- **M5 坐席话术和快捷回复**：新建的正文是工作台发送的英文原文，对应 I6 草稿只预填英文。I6 保存和发布这些键时要求英文及已选运营区域语言，未选且留空的中越用同一英文补齐；保持变量校验。M5 启用话术前需已发布的 I6 英文与正文一致，中文不需要等于英文。已发布的存量话术不自动改写，旧草稿若需重新启用应按英文原文重新登记。

## App 可见的单栏运营文字（2026-11-18）

I5 法域目录名称，E1 商品的名称、角标、副标题、GPU、功耗、机房、在线率、质保和资料名称，E2 PHONE 任务名称，A1 账号显示名，以及 H4 转盘奖名和地区赛各地区名，新增或编辑时填写英文。写入校验按 Unicode Han 判断，包含扩展区，允许正常型号、数字、标点和无汉字的名称。已有 A2 建单和审批回放入口也做同一校验。失败返回 HTTP 422，`message` 为 `APP_TEXT_CHINESE_NOT_ALLOWED`，`data.field` 是实际字段路径。上线前冻结的含汉字提案可按原流程退回并重新提交。账号显示名原样提交时允许邮箱或头像变更。规则和起止时间原样提交时允许已开启的地区赛关停。

实物交付以一个正的瓦数为准。单卡额定可填 `575W (per-GPU rated)`，显卡额定合计可填 `1,800 W (combined GPU rated)`。`W TDP` 和旧记录的两个中文限定语仍可用于交付。

前向迁移按稳定 ID 和原值精确更新五个法域的目录、映射以及两套 E2 种子目录名称。I5 目录命中时递增 revision。法域的国家映射、已发布版本、哈希及确认状态继续有效。存量非种子内容按以下清单处理，历史抄本与已发布策略版本保留原文。

### 存量检查（只读）

在目标 MySQL 8 库的同一会话运行以下查询。处理后可原样复查。结果按字段、稳定 ID、来源、可改入口或历史属性标记。E1 分别读取商品主表和 SKU。旧 SKU 经启动兼容回填主表后，即可在 E1 列表找到并修改。E2 按业务时区取得当前生效版本，只有当前属于 PHONE 的任务可在 E2 编辑。进行中会话的负责人名称是分配时的抄本，需在会话中核对。

```sql
SET NAMES utf8mb4;
SET @han = CONVERT(CONCAT(CHAR(92), 'p{Script=Han}') USING utf8mb4);
SET @business_now = CONVERT_TZ(UTC_TIMESTAMP(6), '+00:00', '+08:00');
START TRANSACTION READ ONLY;

WITH sku_copy AS (
    SELECT product_no COLLATE utf8mb4_0900_ai_ci AS stable_id, 'nx_product' AS source_table,
           JSON_OBJECT('name',name,'badge',badge,'tagline',tagline,'gpu_model',gpu_model) AS fields
      FROM nx_product WHERE is_deleted=0
    UNION ALL
    SELECT sku_id, 'nx_admin_device_sku',
           JSON_OBJECT('name',name,'badge',badge,'tagline',tagline,'gpu',gpu,
                       'power_text',power_text,'datacenter',datacenter,'uptime',uptime,
                       'warranty',warranty,'spec_document_title',spec_document_title)
      FROM nx_admin_device_sku WHERE is_deleted=0
), task_versions AS (
    SELECT task_type_id, version, name, pool_code,
           ROW_NUMBER() OVER (PARTITION BY task_type_id ORDER BY effective_at DESC,version DESC) AS version_order
      FROM nx_sim_task_type_version
     WHERE effective_at<=@business_now
), current_copy AS (
    SELECT CASE k.column_name WHEN 'gpu_model' THEN 'gpu' WHEN 'power_text' THEN 'power'
               WHEN 'spec_document_title' THEN 'specDocumentTitle' ELSE k.column_name END
               COLLATE utf8mb4_0900_ai_ci AS field,
           s.stable_id COLLATE utf8mb4_0900_ai_ci AS stable_id,
           CONCAT(s.source_table,'.',k.column_name) AS current_source,
           JSON_UNQUOTE(JSON_EXTRACT(s.fields,CONCAT('$.',k.column_name)))
               COLLATE utf8mb4_0900_ai_ci AS current_value,
           'E1 修改' AS edit_entry
      FROM sku_copy s
      CROSS JOIN JSON_TABLE(JSON_KEYS(s.fields),'$[*]'
           COLUMNS (column_name VARCHAR(64) PATH '$')) k
    UNION ALL
    SELECT 'name', jurisdiction_code, 'nx_disclosure_jurisdiction_catalog.jurisdiction_name',
           jurisdiction_name, IF(status='ARCHIVED','只读保留（已归档）','I5 法域目录改名')
      FROM nx_disclosure_jurisdiction_catalog WHERE is_deleted=0
    UNION ALL
    SELECT 'jurisdictionName', jurisdiction_code, 'nx_disclosure_jurisdiction.jurisdiction_name',
           jurisdiction_name, 'I5 矩阵抄本，通过原审批流程按已发布版本重存'
      FROM nx_disclosure_jurisdiction WHERE is_deleted=0 AND status='PUBLISHED'
    UNION ALL
    SELECT 'name', d.task_id, 'nx_admin_device_task.name', d.name,
           IF(v.pool_code='PHONE','E2 编辑 PHONE 任务','只读保留（当前无 PHONE 策略）')
      FROM nx_admin_device_task d
      LEFT JOIN task_versions v ON v.task_type_id=d.task_id COLLATE utf8mb4_unicode_ci AND v.version_order=1
     WHERE d.is_deleted=0
    UNION ALL
    SELECT 'name', CONCAT(task_type_id,'/v',version), 'nx_sim_task_type_version.name',
           name, IF(pool_code='PHONE','E2 发布新策略版本，现有版本保留原文','只读保留（旧策略无任务池）')
      FROM task_versions WHERE version_order=1 AND (pool_code='PHONE' OR pool_code IS NULL)
    UNION ALL
    SELECT 'displayName', CAST(id AS CHAR), 'nx_admin.nickname', nickname, 'A1 编辑账号资料'
      FROM nx_admin WHERE is_deleted=0
    UNION ALL
    SELECT 'ownerAgentName', conversation_no, 'nx_conversation.owner_agent_name',
           owner_agent_name, '客服会话分配抄本，按会话分配和转接流程核对'
      FROM nx_conversation
     WHERE is_deleted=0 AND archived=0 AND owner_agent_id IS NOT NULL AND status IN ('OPEN','TRANSFERRED')
    UNION ALL
    SELECT 'rewardName', tier_name, 'nx_growth_wheel_tier.reward_name', reward_name,
           CASE WHEN status<>1 THEN '只读保留（已退役）'
                WHEN LOWER(reward_kind)='points' THEN '只读保留（仅可退役）'
                ELSE 'H4 编辑转盘奖项' END
      FROM nx_growth_wheel_tier WHERE is_deleted=0
    UNION ALL
    SELECT CONCAT('regions[',r.ordinal-1,'].name'), e.event_code, 'nx_growth_event_rule.rules_json',
           r.region_name, IF(e.activated_at IS NULL,'H4 编辑地区赛草稿','已锁定规则，保留原文')
      FROM nx_growth_event_rule e
      JOIN nx_event_quest q ON q.quest_code=e.event_code AND q.is_deleted=0
      CROSS JOIN JSON_TABLE(e.rules_json,'$.regions[*]'
           COLUMNS (ordinal FOR ORDINALITY, region_name TEXT PATH '$.name')) r
     WHERE e.kind='regional'
)
SELECT field,stable_id,current_source,current_value,edit_entry
  FROM current_copy WHERE REGEXP_LIKE(current_value,@han,'c')
 ORDER BY field,stable_id,current_source;
```
