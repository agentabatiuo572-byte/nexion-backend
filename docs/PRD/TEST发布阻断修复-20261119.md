# TEST 发布阻断修复

## H3 首日邀请任务和注册

升级已有数据库时，同一事务补齐缺失的「邀请好友」任务和 `REFERRAL_SETTLED` 完成事件绑定。安装顺序保证注册校验在两项就绪后运行。还支持旧脚本只留下已启用任务的情况。保留原任务和绑定的状态，重复升级维持原记录。已有冲突由原注册完整性条件拦截，要求先核对配置。

## F1 发券奖励撤销

待付款订单占用的奖励券撤销时标为已作废，并保留原订单关联。原订单按锁定价格继续处理，取消或超时之后该券仍为已作废。钱包和账本不产生扣回记录。只有能确认原订单已付款并保存了正数抵扣金额时，才可按已审批的选项扣回。历史券缺少金额或结算证据时，回执说明跳过原因。重复审批沿用原回执。

## CREGIS 新库与已有库

先确保两张人工资金准备表存在，再执行网络字段升级。空库直接创建最终结构。已有表保留行和原业务唯一键，旧记录默认归为 BEP20，新增和查询可按 BEP20 或 ERC20 区分。建表步骤仅建立结构，供应商配置沿用现有配置流程。
