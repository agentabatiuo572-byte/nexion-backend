# B149 本周任务实际到账额

App 首页和任务中心通过 `GET /api/quests/state` 读取本周任务。已领取的一档和二档任务在原有 `rewardNex` 之外，可返回 `creditedRewardNex`。它是六位小数的 UVT 金额字符串，例如 `"137.500000"`。原有 `rewardNex` 继续表示任务基础奖励。

实际到账额以本人、该任务、该周实例的 `QUEST_REWARD` 入账记录为准。刷新、重启或换设备读取同一周实例时，从该记录读回原金额。现行倍率、别人的同一任务或另一周实例不会参与计算。

未领取的任务，以及没有查到对应有效入账记录的历史已领行，省略 `creditedRewardNex`。客户端在缺少该字段时显示原状态。首日任务继续使用自己的领取与奖励合同。

周任务领取仍以冻结周实例的截止时间为准。截止后，原请求键可继续查回已领取回执。
