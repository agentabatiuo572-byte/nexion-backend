# H9 首页与网络展示配置（2026-10-28）

## 模块与入口

H9 按「首页数字增长、首页网络实况、全球网络、设备预估排名、历史估算」集中配置。每个模块只展示相关输入、说明与保存按钮；切换模块保留未保存草稿。刷新及保存不清空其他模块的草稿。

介绍页在线设备/累计已发放继续读取首页数字增长；首页网络实况的注册人数读取注册基数与增长规则，在线设备与介绍页共用当前批次；设备预估排名仍按独立排名配置计算。真实设备、余额和任务不受这些展示设置影响。

设备预估排名的表格、开关、输入、帮助和底部操作统一使用 H 域样式。

## 全球网络

全球网络继续明确标识「模拟数据」。固定的8个城市、坐标与翻译属于静态内容；节点基数、基础延迟和变化参数由 H9 配置，经公开配置接口读取。App/H5 不内置数值回退。无有效配置时数值显示占位，地图和城市入口仍保留；读取新配置后更新指标。动画计时器不重复请求接口，隐藏页面暂停采样，恢复按当前时间与最新配置显示。

| 配置 | 合法范围 |
|---|---|
| 数据变化间隔 | 1–86400秒，最多3位小数；存储为整数毫秒 |
| 节点浮动上限 | 0–100%，最多6位小数 |
| 并发任务占比上下限 | 0–100%，下限≤上限，最多6位小数 |
| 每任务小时处理量上下限 | 0–10000，下限≤上限，最多6位小数 |
| 延迟浮动上限 | 0–60000整数毫秒 |
| 每中心在线节点基数 | 0–100000000整数 |
| 每中心基础延迟 | 0–60000整数毫秒 |

8个中心必须完整且无重复：新加坡、东京、胡志明市、伦敦、巴黎、法兰克福、纽约、圣何塞。在线节点由基数加平滑浮动，进行中任务由节点与任务占比计算；每小时任务与延迟使用对应上下限。页面总数是8中心之和。

沿用既有全球网络基线迁入后端：5400ms、节点浮动0.4%、任务占比8–14%、小时处理量2.2–3.8、延迟浮动6ms；各中心基数/延迟为236000/18、253000/22、163000/26、249000/16、208000/20、217000/14、316000/24、284000/17。不隐式开启其他模块。

## 保存、权限与兼容

每次保存只合并当前模块草稿和最新已保存值；仍通过 H9 原有权限、版本校验、理由确认、幂等与审计。设备排名沿用其独立接口与版本。其他模块若有未保存修改且服务端同字段发生变化，保留草稿并提示刷新，不覆盖他人设置。保存失败不宣称生效，刷新失败保留已有内容。

全球网络配置使用现有 H9 聚合内的 `globeDisplay` 字段，不新增资金配置或通用缓存。旧记录由后端补足原展示基线；旧客户端省略此字段时保留已保存配置。旧客户端重试使用原 H9 指纹，避免升级后误判同一幂等请求。
