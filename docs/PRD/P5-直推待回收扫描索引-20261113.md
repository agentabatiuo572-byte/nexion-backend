## 最小变化与业务边界

MySQL 8.4 的[功能索引](https://dev.mysql.com/doc/refman/8.4/en/create-index.html)使用内部隐藏虚拟生成列；索引本身保持 VISIBLE，不新增业务可见列。`SupportDirectReferralReadMapper.SETTLEMENT` 读取 `s.*`，资金证据使用固定 mutable 字段集合，所以本批不引入可见pending flag，不修改资金证据或允许字段。

两资产OR、原环境/run、`id>cursor`、id升序、100条上限和 `id/settlementNo/refundRatio` 三个返回字段完整保留。原查询没有状态或软删除过滤，本批不新增任何此类条件。保留调度间隔、lane数量、游标重置、退款、金额、自然重试、幂等、账户/钱包锁和600秒任务规则，不改其他查询、鉴权、页面或数据可见范围。
