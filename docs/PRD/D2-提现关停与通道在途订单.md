# 提现关停与通道在途订单

关闭 J1 提现开关后，提现派发器停止领取已批准、尚未提交给通道的订单。这些订单继续保留审核结果和预占资金。关停期间不会因派发增加尝试次数、设置派发租约或生成新的通道请求。主开关缺失时读取旧开关，两者都缺失则停止领取。

Cregis 的 BEP20 和 ERC20 在领取事务中读取并锁住开关状态，与关停操作确定先后顺序。HDPay 越南盾提现继续在既有 D2 派发检查中复核同一开关。关停前已提交派发意图的订单继续按原通道请求键处理。已有通道单继续查单、核对回调，链上单继续核对确认。Cregis 没有通道单号的未知提交保留待核对状态，沿既有证据恢复流程处理。关停不触发退款或重复提交。重新开启后，待领取订单按原条件恢复派发。

派发租约、通道重试与未知提交超时按数据库存储时区判断，和重试计划的时间口径一致。JVM 本地时区与存储时区不同时，仍等到原计划时间再重试。
