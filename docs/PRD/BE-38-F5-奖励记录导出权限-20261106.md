# BE-38 F5 奖励记录导出权限

F5 奖励记录查询和异常列表使用 `network_f5_read`。`POST /api/admin/commissions/export` 使用 `network_f5_export`，继续校验导出理由、筛选条件及行数和大小上限，并记录脱敏 CSV 导出审计。

首次迁移只给旧接口已授权的有效角色补发导出权限。旧接口同时要求 F5 读取权限与网络域的非只读权限。标准角色中，超级管理员、增长运营、财务主管和风控主管满足这两项。自定义角色也须在同一角色内满足两个条件。导出权限只用于该导出接口。

隔离验收覆盖原有导出角色、既有自定义导出角色、只有读取权限的账号和只有导出权限的账号。检查拒绝状态、授权下载、导出理由、脱敏标识和审计记录，并核对迁移重跑后保留已撤回的授权。
