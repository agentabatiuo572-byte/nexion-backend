# B32 今日概览销售和每日资金流

`GET /api/admin/bi/finance/revenue` 仅在 `device_sales` 行新增 `orderCount` 和 `previousOrderCount`。笔数和销售额读取同一批已支付、已完成订单，按付款时间归属业务日，沿用缺失付款时间时取创建时间的口径。已退款订单不再计入。按日查询时比较日为昨天全天。

`GET /api/admin/bi/finance/daily-flows?days=8` 沿用 `bi_l3_read` 权限，默认读取 8 天。可查询 1 至 31 天，超出范围返回 HTTP 400 和 `L3_DAYS_INVALID`。结果按 LEGACY 业务日升序，最后一行是今天。

- `days` 中每行包含 `date`、`userTopupUsdt`、`userTopupCount`、`withdrawalUsdt` 和 `withdrawalCount`。响应同时包含 `generatedAt`。
- 用户充值按 D1 账本到账口径统计链上、卡和 HDPay。银行卡沿用含手续费的 D1 金额，按账本到账时间归日。财务注资不计入。
- 提现取 USDT 已完成单的本金金额。只认 `CONFIRMED` 或 `SUCCESS` 且有完成时间的单，按完成时间归日。
- 金额保留两位小数。无资金记录的业务日仍返回一行，金额和笔数均为零。
