# B1 资金覆盖率告警确认恢复

B1 的确认只对当前告警生效。当 B 域取得可靠的真实快照，且可计量的覆盖率达到健康线时，后端清除已保存的确认。处于警戒区、缺少估值价格或没有可用于计算覆盖率的应付款时，确认保持原样。

清除确认后，再次跌破红线会返回未确认的告警。在幂等记录的 24 小时有效期内，历史确认请求按原请求键返回旧回执；新告警使用新请求键确认。

成功登记 D3 储备注入时，也在注资的同一事务中锁定现有确认并读取注资后的真实覆盖率。可靠且达到精确健康线才清确认，不依赖此时打开 B 域页面；若随后再破线，旧确认不会遮住新告警。健康判断使用未舍入金额与当前生效健康线交叉相乘比较，估值使用当前生效价格；不使用展示百分比或拟生效价格。警戒区、显示值舍入到健康线、估值不可用和零应付款均不触发清除。注资失败回滚同时保留原确认。在幂等记录的 24 小时有效期内，重放已成功的原注资键只返回原回执，不清除后来新确认的告警；有效期过后重新执行时，已登记的合法凭证以 `409 VOUCHER_ALREADY_REGISTERED` 拒绝，仍不改变确认。

恢复仍以 B 域现有观测或成功 D3 注资取得的真实覆盖快照为准。拟生效价格与其他只读覆盖率预览不清确认；没有新增定时采样或全域账务观察。其他来源在两次现有观测之间曾恢复又跌落，且没有成功 D3 注资取得该健康状态时，仍不会触发复位。
