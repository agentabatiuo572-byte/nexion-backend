## 1. 实际读取链与问题

### Developer docs

`PublishedDeveloperDocsService.adminView:56-67`:

1. `read()` → `config.activeValue(CONFIG_KEY)` → `PlatformConfigFacadeAdapter.activeValue` → `PlatformConfigRepository.findActiveByKey` → MyBatis；DB 异常为 RuntimeException。
2. `.orElse("{}")` 表示配置缺失；`mapper.readValue(raw, Map)` 解析 JSON，坏 JSON 抛 checked Exception；JSON `null` 返回 null。
3. 空 map 走 `defaultAdminDocument()`（随包默认、revision 0、defaultContent）；
4. `PublishedContentSnapshot.admin` + `markDefaultPublic`；返回 200 默认。
5. **当前 catch (Exception) 把 DB 异常、坏 JSON、post-processing 异常全部转 200 `{status:UNPUBLISHED,...}`**；现有非空但坏 shape 的 JSON（例如 `{"foo":1}`）也不校验，直接 200 带 source/configKey，既不是默认也不是故障。
6. 默认资源本身在构造 bean 时 `parse(defaultDocument)`；默认资源坏会在启动失败，不是 adminView 的 catch；不能把启动错误算成此处默认。

### How content

`PublishedHowContentService.adminView:91-107`:

1. 同样 `read()`→config/repository/Jackson；`{}`/null 行为同上。
2. 当前 `hasAdminDocumentShape` 返回 false 时用默认文档；异常 catch 也用默认文档+source/configKey 返回 200。
3. `hasAdminDocumentShape` 检查 version/status/contents/所有 6 key/revision；不校验每 locale/block；DRAFT 可缺页、PUBLISHED 全六键。
4. **当前 DB/JSON/post-processing 异常和坏 shape 都被伪装成正常默认内容**，与“确实没有自定义发布/随包默认”不可区分。

### 公开读取/更新/写回执

- 公开 `publicDocument` / `publicContent` 也 catch 并返回既有 503 错误；本次不改，不能套用 admin fix 改公开输出。
- `update`/`update` 的 `read(true)` 不经过 adminView catch；成功写回执/审计/ CAS/默认首发规则不改。
- **不共享 adminView 的失败返回给 update**；避免已成功写被新读取错误伪装失败。
- 两个 Controller 只把 `adminView()` 返回原样 `ApiResult`；PC 仍由 GET 读，无新字段/状态。
- `PublishedRankHowPolicyService`/`PublishedPrivacyPolicyService` 有类似 catch，但原行只点名 A3 developer/how；本次不扩到它们。

## 2. 最小候选

只改两个 **adminView** 边界：

- Developer:
  - `read()==null` → 503 `DEVELOPER_DOCS_UNAVAILABLE`。
  - `read().isEmpty()` → 现有默认文档（配置确实缺失/无自定义发布）。
  - 非空但 `hasAdminDocumentShape` 失败 → 503 同上（不返回 200 UNPUBLISHED）。
  - catch read/parse/admin/shape 异常 → 503 同上，不再返回 200 `{UNPUBLISHED}`。
  - 新 shape 检查只做顶层：version 非空 String、status∈UNPUBLISHED/DRAFT/PUBLISHED、locales 非空 Map、revision 非负整数；不改内容校验/public validator。
- How:
  - `read()==null` → 503 `HOW_CONTENT_UNAVAILABLE`。
  - `read().isEmpty()` → 现有默认文档。
  - 非空但既有 `hasAdminDocumentShape` 失败 → 503 同上（原逻辑改为错误，不再默认）。
  - catch read/parse/admin/shape 异常 → 503 同上，不再默认 200。
- 成功默认/首发 revision0/默认 publicSource/flags 不变；成功响应 shape、source/configKey 不变。
- 默认资源、环境解析、runId、语言、公开 App/H5、发布写链、CAS、审计、权限、PC/App/H5 均不改。
- 没有新状态字段/错误码；复用现有公开不可用错误码 503。
- 没有新 catch 吞错；没有删除合法默认内容。
