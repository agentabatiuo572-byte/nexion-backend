# BE-23 数值输入边界

依据 T14 和 B30 第 23 项。适用于储备注入、App 组合购阶梯折扣、旧活动目标与代金券模板的后端写入。

- D3 `/api/admin/treasury/reserve-injection` 及 `/api/admin/treasury/injections` 只接受正数且最多两位小数。超精度返回 400 `D3_INJECTION_AMOUNT_PRECISION_INVALID`，发生在幂等认领和储备写入前。合法请求原键可跨别名恢复，既有储备明细保留原记录。
- E1 新写入的三档折扣均为 0.01%–30%，并保留按件数不下降的规则。直接更新、A2 新提案和已有提案批准回放使用同一边界。既有配置按原规则读取，可由合法的新配置替换。
- H3/H4 旧活动的新建请求可省略目标值并默认 1，显式目标须为 1–1,000,000,000 的整数。非跟踪活动保留内部 0 的状态表示及既有统计和领奖行为，历史活动保留原数据。
- H7 折扣券新建及编辑只收整数 1–99。模板存在任一已发记录时，包括后来使用或作废的记录，修改类型返回 409 `H7_VOUCHER_TYPE_LOCKED_AFTER_ISSUE`。未发券模板可变更类型。同类型编辑仍校验新折扣，已发券记录和历史读数保留。
