# A4 登记双人审批

BE-09（DEC-A-07）覆盖 A4 新事件登记、给已有事件新增字段和登记域扩展批次。具有 `platform_a4_write` 的后台账号通过 A2 提交。另一位处于启用状态且具备 `platform_a2_operation_approve` 的超级管理员审批，发起人不能审批自己的单。

- 三个登记 POST 对持有 A4 写权限的直接请求返回 `409 A2_CONFIRMATION_REQUIRED`。生命周期、留存、采样等现有操作仍按各自流程处理。
- A2 票据以规范化事件名标识对象，事件与字段登记共用事件对象锁。票据记录原登记字段、理由和事件目录版本。审批前事件、字段、扩展批次及目录版本均保持原状。
- 批准后通过现有登记服务执行。新事件和新增字段仍校验冻结的目录版本，版本已变更时拒绝执行并保留待批单。域扩展批准后按既有规则登记批次。
- 发起人可凭原幂等键查询自己的票据，仍需持有 A4 写权限。响应丢失后的同键重试不会新增票据，也不会执行登记。
