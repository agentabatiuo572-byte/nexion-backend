# A3 内容读取与 B3 阶段筛选

## A3 内容读取

拥有 `platform_a3_read` 的运营账号可通过 `GET /api/admin/developer/docs` 和 `GET /api/admin/content/how-it-works` 读取开发者文档和产品说明。对应的 `HEAD` 沿用同一读权限。两个接口分别返回现有发布版本或草稿及其发布状态。写入沿用各接口现有的权限校验，开发者和内容域其他路径继续按各自的权限校验。

## B3 运营阶段

B3 按注册事件的 `phase` 归属筛选。`SYSTEM` 对应「系统默认」，与 `P1` 至 `P6` 一样可用于漏斗总览、辅助指标、趋势、CSV 和保存视图。后续事件仍按同一注册用户的实际发生顺序纳入漏斗。空值与 `ALL` 表示全部阶段，其他阶段值返回 `422 B3_PHASE_INVALID`。

阶段选项来自已有注册事实，使用与请求相同的合法值范围。合法组合没有匹配注册时保留可用筛选选项和「暂无法计算」状态，便于切换回有数据的筛选。
