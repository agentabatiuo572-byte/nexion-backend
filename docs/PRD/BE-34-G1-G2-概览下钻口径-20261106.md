# BE-34 G1、G2 概览下钻口径

依据 B30 第 34 项、S22 与 G-DEC15。

- G1 `GET /api/admin/market/staking` 的持仓状态计数与清单只取四档历史 USDT 质押，排除已删除记录。提前解锁按 `early_withdrawn_at` 取 LEGACY 业务月，包含月初，截止于下月月初之前。其他状态保持不限月份。
- G2 `GET /api/admin/market/exchange` 的个人额度、平台额度及地区拦截总数与清单按各自状态和 `created_at` 取当前 LEGACY 业务日，包含日初，截止于下一业务日之前。排队清单仍可跨业务日。
- 分组总数按符合范围的全部记录计算。G1、G2 各组明细保持既有排序并最多返回 50 条。
