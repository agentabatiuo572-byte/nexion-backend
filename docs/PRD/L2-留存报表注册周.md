# L2 留存报表注册周

创建 `FUNNEL_COHORT` 报表时，CSV 的「阶段或同期群」列对留存行写入本次快照中的注册周，与同一切片的 L2 留存数据一致。每行同时保留注册人数及 Day1、Day7、Day14、Day30、Day60 的留存率。未成熟的留存率保持空白。

下载返回创建时保存的快照，历史文件仍可按原权限下载。需要带注册周的历史范围报表时，可以按相同切片重新导出。
