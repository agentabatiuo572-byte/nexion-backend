# BE-45 H2 试用记录待审批

H2 `GET /api/admin/growth/trials` 的试用记录在当前授权分页存在有效 A2 待审批锁时带 `pendingApproval`，包含动作、提交人与提交时间。未锁定记录省略该字段。历史锁可沿用同一试用记录的裸编号；只有可以与原工单绑定的元数据才显示。试用业务状态继续来自试用记录。

H2 强制取消的直接入口将原编号或裸编号解析到同一真实试用记录，再检查两种已有锁。待批时拒绝新的直接取消并返回 `OBJECT_LOCKED_BY_A2`。完成、拒绝、撤回或到期的审批不再标记待批。

2026-11-07 起强制扣款按 [BUG-310 退役约定](BUG-310-H2-强制扣款退役-20261107.md)拒绝新执行及新提案，旧待审扣款也不可批准执行；历史待审投影与原键结果读取保持，原提交者仍可撤回，审批者仍可拒绝。
