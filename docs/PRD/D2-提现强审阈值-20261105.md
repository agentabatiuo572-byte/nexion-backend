# D2 提现强审阈值

对应 BUG-288。

- App 提现试算、提交与 D2 放行使用 A3 生效配置 `withdrawal.strong_review_threshold_usdt`。提现金额达到阈值即为大额。大额只可由财务主管或超管凭放行权限单笔操作，且需确认收款地址。批量放行将大额单分流至单笔审核。
- H1 自动审核候选单到期时再次检查当前阈值，含银行提现。已达到阈值或阈值不可用的候选单转待审核。提交时记录的审核原因仍按当时事实保留。
- D2 队列和详情保留现有字段，同时在订单上提供 `strongReviewThresholdUsdt` 和 `addressVerificationRequired`。配置缺失或无效时两项为 `null`，App 试算及提交、D2 单笔及批量放行均以 `A3_STRONG_REVIEW_THRESHOLD_UNAVAILABLE` 拒绝。
