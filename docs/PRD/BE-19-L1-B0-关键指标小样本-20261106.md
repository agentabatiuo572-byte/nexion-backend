# BE-19 L1 与 B0 关键指标小样本

依据 B30 第 19 项与 T10。阈值固定为 5，按每项指标在当前筛选下的独立分母人数判断。Genesis 售罄的 1,000 是库存量，小样本判断采用同一筛选和区间内的去重购买者人数。

- 少于 5 人时，L1 当期指标返回 `suppressed: true`。指标值、分子、分母和解释中的分子分母副本为空，B0 兼容投影的指标值和达标状态也为空。
- 上期和各趋势点独立判断。任一环比所用区间被抑制时，环比为空。受抑制的趋势点保留原位置，以 `null` 与对应标记返回。其他合法趋势点保留数值。
- 新生成的 KPI CSV 在当前指标不可用原因或对应趋势列中写「样本过小」，被保护的当前值、分子和分母留空。只含小样本的当前筛选也可导出标记。既有报表下载、权限和筛选按原流程处理。
