# BE-19 L1 与 B0 关键指标小样本

依据 B30 第 19 项与 T10。阈值固定为 5，按每项指标在当前筛选下的独立分母人数判断。Day0 接入和注册后浏览商城与 B3 共用相同的转化事件，分子不足 5 人也触发保护，适用于当期、上期、趋势和新导出。Day7 及其他比率仍按各自分母判断，达到门槛的有效 0% 保留。Genesis 售罄的 1,000 是库存量，小样本判断采用同一筛选和区间内的去重购买者人数。

- 少于 5 人时，L1 当期指标返回 `suppressed: true`。指标值、分子、分母和解释中的分子分母副本为空，B0 兼容投影的指标值和达标状态也为空。
- 上期和各趋势点独立判断。任一环比所用区间被抑制时，环比为空。受抑制的趋势点保留原位置，以 `null` 与对应标记返回。其他合法趋势点保留数值。
- 新生成的 KPI CSV 在当前指标不可用原因或对应趋势列中写「样本过小」，被保护的当前值、分子和分母留空。只含小样本的当前筛选也可导出标记。既有报表下载、权限和筛选按原流程处理。

## L1 按注册周／月（BUG-235、L1-BE-01）

- L1 总览、指标详情、趋势及 CSV 可选择按真实注册周或月统计。周从周一开始，沿用后台业务日历。自定义范围不会自动扩展到整个周或月，边缘批次标为不完整。
- 同一次查询或导出使用一个观察截止时间。Day0 和 Day7 只计完整经过对应观察期的用户。部分成熟标为暂定，全部未成熟时留空。
- 缺权威注册事件或查询超过事件保留的可靠边界时，相应指标显示来源不全。小样本规则适用于汇总和每个批次，受保护的人数、指标值和 CSV 单元格均留空。总值按选中用户重新计算。
- 分组时，第 8 项全平台售罄速度标为不适用，达标项按 7 项统计。分组环比暂为空。
- 导出使用查询返回的观察截止时间，每行对应一个指标和一个注册批次。已有报表保留创建时的结果。不选择分组时，L1 与 B0 继续使用原六点数据，旧导出及历史请求保持兼容。
