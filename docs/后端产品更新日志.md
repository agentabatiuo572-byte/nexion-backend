# 后端产品更新日志

## 2026-11-18 — B26 界面语言开关

- 只有英文必开；未配置时默认开启除中文外的八种界面语言。运营已保存的配置保留，中文和越南语可关闭，内容存储三语分组不变。
- 手机注册及资料语言更新把合法但已关闭的语言保存为 `en`。注册数据库、欢迎语入参和注册事件保持一致；资料更新返回真实保存值并记录同一值的审计。未知代码仍拒绝，资料读取和消息交付规则不变。
- A3 保存继续使用现有权限、版本、理由、审计和幂等规则，省略语言字段保留现值；不新增迁移覆盖运营配置。
- FAQ 的英文请求缺稿时返回空，越南语请求缺稿时使用英文。课程及测验在英文或越南语请求下缺少可读内容时省略该课，详情或开始接口返回 `LEARNING_COURSE_UNAVAILABLE`。活动启用前后端仍检查中、英、越三语的标题、说明和奖项名称。有规则的非转盘活动，活动列表和详情接口返回的 `rewardName` 优先使用实际请求语言的已发布运营文案，缺少时返回规则计算的摘要；转盘和无规则旧活动沿用请求语言、英文、原始奖项名称的读取顺序。奖励明细和发放金额不变。
- A3 增加独立的运营区域语言 `operatingLanguages`：英文固定必选，可选中文、越南语，缺省为 `["en"]`。任一已登录运营账号都可从管理端只读接口取得该值，用于决定内容发布必填语言。该字段仅在管理端提供。
- I4 信任版块、I5 风险披露草稿在后端只要求英文及已选运营区域语言。未选的中文或越南语整组留空时，保存时用英文补齐对应字段；部分填写仍须补齐。I4 公开快照要求各本地化字段族有英文。I5 占位符以英文比对，审批发布沿用已保存的三语内容和哈希。
- I1 文案、I6 词条和 I7 课程与测验写入时要求英文和已选运营区域语言。未选的中文、越南语整组留空时保存英文副本；部分填写仍须填齐。会话脚本和模板词条继续要求中文。I1 一次点击可保存改稿并发布。I6 重扫只将缺少必填语言的词条列入待修。I7 验收沙箱课程目录按正式课程内容规则校验和补齐。
