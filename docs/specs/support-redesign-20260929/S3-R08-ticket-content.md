# R08 工单私聊副本权限

私聊正文仅当前顾问和主管可阅；工单状态和内部备注仍按原权限协作。工单负责人取当前专属客服，变更走主管正式客户转绑，详见[工单专属客服归属](../../support-ticket-ownership.md)。

工单新增 `sourceConversationNo`：`DIRECT` 表示新建普通工单；真实会话号表示转换来源；`null` 表示历史来源未知。转换来源必须由同一事务写入。历史回填只接受热审计与归档审计中的转换事件，核对会话、工单存在且属于同一客户；多源或不匹配保持未知。未知历史保守限制，不凭正文前缀或缺少转换记录认定普通工单。

`contentRestricted=true` 时标题、摘要和客户侧消息正文返回受限提示；内部备注与系统记录保留。当前顾问或主管还须具备 `service_m3_read` 才能读取私聊副本；App 客户只能读取自己的工单。原有工单协作权限不变。关键字查询的匹配和计数使用相同阅读条件。

幂等成功记录不改写；返回前按当前权限重新投影受限工单，避免旧正文经回放泄漏。后续前端根据 `contentRestricted` 显示受限状态，不把空正文误解为数据丢失。

迁移输出可靠来源数、未知来源数、坏审计数与未知工单清单。旧普通工单仅凭独立普通创建事件（Admin 的 detail.userId 或 App 的顶层 userId）与真实工单客户精确匹配、且没有转换冲突时回填 DIRECT。热审计和归档均检查；缺证、坏数据或冲突保留未知。无新增来源管理页面。恢复采用迁移前备份；旧程序不会执行该阅读策略，不能将旧程序连接迁移后的库作为安全回滚。
