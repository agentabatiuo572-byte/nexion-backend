# USDT-BSC 归集与甲方付款准备

本轮仅交付资金操作准备、双人复核和只读检查，不发送资金。现有用户充值、提现和异常退款保持原合同。新流程不调用 `collection`、`payout` 或任何签名/广播接口，不注册资金发送定时任务。

## 配置与业务路径

- 网络固定 BSC，币种固定 USDT，合约为 `0x55d398326f99059ff775485246999027b3197955`。
- Cregis 项目 `1466552794661984`。归集接收及甲方付款来源为项目绑定钱包的 `0x0fe784237f21e7b7d74082cb265d7b4e1c91fdad`。
- 甲方接收地址为用户确认的 `0x43e22c774baae7543b45d365050059d5fcef7e97`。Cregis 内已保存 USDT-BSC 白名单。
- 归集来源只能选择本项目已分配的 READY 子地址；甲方付款来源只能为平台钱包。地址不由浏览器自由覆盖。
- 运营填写人工确定的正数金额、业务参考号和理由。建单、复核和取消均只保存准备记录，不改变用户余额或储备，不表示已支付。
- 同一项目、操作类型和业务参考号只能创建一单；采用现有持久幂等键和版本 CAS。复核必须由另一位仍有效、具有相同资金权限的管理员进行。
- 实际归集和付款须在未来另行取得真实转账授权后，由 Cregis 客户端执行。准备单的金额、来源、目标和编号用于核对，审批不自动发送。
- 此处不开放其他网络/币种，不把甲方当成用户提现收款人，不把归集当成用户充值再次入账。

## 状态及接口

`DRAFT → REVIEWED`（另一管理员核对）或 `DRAFT/REVIEWED → CANCELLED`（有资金权限的管理员填写理由，可取消失效创建者遗留单）。没有 SENT、SUCCESS 或余额入账状态。列表仅为操作准备记录，真实付款结果仍须后续以 Cregis 订单和链交易核验，不能手工把准备单标为付款成功。

所有接口位于 `/api/admin/finance/cregis/funds-preparation`：

- GET `/status`：固定配置、支持的来源地址及执行关闭事实；无供应商写调用。
- POST `/preflight`：对选定来源只读查询 Cregis 地址归属、BSC USDT/BNB 余额和现有风险/对账能力；读取失败返回未知，禁止显示零或已就绪。BNB 大于零不代表足够支付最终 gas。
- GET/POST `/plans`：本项目分页查询、创建准备单。
- POST `/plans/{planNo}/decision`：另一管理员复核或由具有资金权限的管理员取消，校验预期版本及理由。

读取需要 `finance_d1_read`；写入及预检另需 `finance_d1_channel_manage`、`finance_d2_withdrawal_approve`，并通过有效 ADMIN 主体检查。新建和审核记录写入必需审计。配置迁移只创建独立准备表并写入上述公开地址，不创建任何发送许可。

风险与回退：新表为纯准备数据；不删除已有资金表或改旧开关。回退代码后保留准备表和审计记录。任何真实转账、自动化权益购买或自动归集开通均不在本轮内。
