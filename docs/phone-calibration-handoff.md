# 手机算力规则交接

## 实施范围与入口

2026-10-03 当前合同采用普通 USER 认证、有效安装标识、设备/任务归属与当前手机绑定。2026-09-28 的 APK 白名单、Android 密钥证明及证明有效期合同已被用户明确取代（superseded），不再是发布前置条件。Janus 保持停用。普通手机激活自动校准；A2 双人审批只用于发布平台规则。

规则按平台、可选精确型号、SoC、GPU、内存区间匹配平台算力值，四个阈值划分五档。它不是物理 TOPS 或实测推理吞吐量；不得以此宣称完成真实 NPU 跑分。未知硬件待核验、不激活、不伪造兜底能力。规则版本只影响后续校准。

APP 新安装登录先停止原手机任务，然后判断是否允许替换及冷却期。显式激活后原子替换绑定，旧仓库手机不可在另一安装激活。原绑定手机恢复仅解除换机暂停并等待新心跳；运营暂停和已购设备不受影响。H5 客户端继续下载引导且不发送手机校准/激活；服务端安装标识不证明请求来源或硬件真实性。在线 APP 保持工作，离线手机按服务端心跳有效期停止。

最小请求合同：`phone-installation/login`、`calibrate`、`activate`、`defer` 直接使用已有字符串 `deviceId`；`phoneRuntime` 使用 `calibrationDeviceId` 并匹配当前 execution binding。数字设备任务 PHONE/MOBILE 的领取与完成必须携带 `X-Phone-Installation-Id`，同时匹配当前 execution binding 和设备 phone binding；其他设备不要求该头。它是普通业务识别，不声称防伪。正常暂缓保留 revision、幂等键和事务，不再使用仅首次允许的 `deferWithoutProof` 路径。

## 发布前配置与限制

1. 先备份数据库，按既有启动迁移流程执行新迁移；独立 MySQL 8.4 已测试重复执行不会覆盖现有绑定。迁移必须先于启用新的服务端入口。
2. 不配置包名/签名白名单，不访问 Android 证明根证书或吊销来源。旧 `/phone-installation/challenge`、`/verify` 入口固定 HTTP 410 / `PHONE_NATIVE_PROOF_RETIRED`，零业务读写。历史表保留，不需要 drop；活动代码不读写原生会话/安装密钥表。
3. E6 建立经核实的硬件规则和算力分界，再由另一名管理员在 A2 核对完整规则并批准。没有默认硬件种子；空配置时手机保持待核验。独立配置允许换机及最短间隔。
4. 客户端与后端协调发布：APP 不再调用旧挑战/验证入口，PHONE/MOBILE 的领取/完成须带安装标识。不能将未带此头的旧客户端宣称为兼容；已购设备继续不要求该头。
5. 不新增安全 toggle、key 或 TTL。普通认证生命周期和现有任务计算证明/lease/结算链保留。Android/iOS 硬件信息以原生采集及服务端规则匹配为准；未实测的平台和后台执行不得宣称通过。
6. 安装身份按应用安装区分；卸载重装可能需要按换机处理。不能把客户端 UUID 宣称为不可变物理手机标识。

## 给验收同事的提示词

请拉取上表的 `test` 并先核对交付提交，不自动合入 `main`。不启用 Janus。先阅读本文件及当前需求、PRD；旧计划中硬件证明内容已被此合同取代。准备两台 Android 真机或两个实际安装 A/B、两个有 E6/A2 权限的不同管理员，以及含手机、仓库旧手机和已购设备的测试账号。

按以下顺序保存请求、数据库前后值、截图及复现步骤；脱敏 token、手机号、签名材料：

1. E6 空配置→新建有依据的硬件规则→试算→取消不写入→提交 A2→发起人自批被拒→第二管理员看到完整版本、阈值、硬件和来源→批准→刷新 E6/A5 一致；测试过期 revision、预约生效、只读角色及后端校验失败。
2. A 首次登录校准：已知硬件自动 MATCHED，不逐个人工审批；未知/冲突硬件待核验，不能激活。补充规则后重试生效；校准到激活期间规则更新须要求重新校准。页面显示平台算力，不显示虚构 TOPS。
3. 激活后刷新/重启仍绑定 A。H5 注册直达下载；旧 H5 校准入口无采集/登记请求、无手机奖励。A 在线时分别用 A/B 浏览器登录 H5，手机任务保持；A 离线后心跳过期停止，不影响已购设备。
4. 禁止换机时 B 登录：A 已领取及暂停未结算手机任务停止，B 提示不可替换，不改绑定时间；A 再登录可恢复执行权，但必须收到新心跳，运营暂停仍保留。
5. 允许换机时 B 登录→重新校准→激活替换槽位；A 再领取/完成任务被拒，仓库 A 不可在 B 激活。冷却期内再次换机被拒；同机重测、暂缓、登出不重置冷却时间。
6. 网络超时、重复点击、进程重启、切账号、令牌刷新、重新同意条款、条款校验与手机登录并发时，不串账号、不重复激活，不丢换机引导。APP 前后台与低电量恢复按原任务门禁运行。
7. 并发登录/心跳/任务完成/激活压力测试；检查无死锁、重复结算或双手机同时执行。所有已购设备继续其原有任务与收益流程。
8. 普通 USER 与有效安装标识可直接登录/校准/暂缓，无额外证明步骤；错误用户、无效 ID、错误安装、解绑及旧安装领取/完成仍拒绝，非手机设备不要求安装请求头。旧挑战/验证入口返回 410 且零写入。验证 GPU 采集恢复图形上下文，长时间前后台不黑屏；iOS 记录原生采集、规则及实际测试边界，不以缺少 Android 证明为封禁原因。

输出通过/失败/未执行三类结果及证据；发现 P0/P1 暂停发布，先修复并重跑同类路径。不得用单元测试或浏览器模拟代替真机结论。
