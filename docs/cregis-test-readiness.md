# USDT-BEP20 TEST 实测入口

适用日期：2026-10-22。配置、费率和开关以测试时的实际回读为准。本说明用于真实交易前准备，不代表供应商签名通知或真实资金闭环已经验收。

## 已具备的配置与入口

- Cregis 项目、服务端密钥和 USDT-BEP20 收款/代付币种已接通；公开 HTTPS 回调分别为 `/api/cregis/callbacks/deposit` 和 `/api/cregis/callbacks/payout`。
- 官方确认的单一出口 `18.143.53.174` 已加入 TEST 配置。两条回调均检查可信对端来源、签名、时间和业务字段；供应商成功还须经过主动查单与 BSC 证明。
- 只读 BSC RPC 已实测链 ID 56、代币 18 位精度、历史及近期 500 区块日志、真实收据和 canonical 区块读取；运行中的完整对账持续成功。公共 RPC 的当前通过不构成生产服务保证。
- 试点账号的专属收款地址已可在 App/H5 钱包充值页显示，二维码解码与页面地址一致，刷新仍为同一地址。不需要手工把一个外部钱包地址填成收款地址。
- D1 可查看地址池余量并补充一个候选地址，系统核验后才可分配。D2 对未知原代付单提供 CID 核对恢复，始终复用原业务号及预留，不重新发款。

## 拿到外部钱包地址后的正常流程

1. 使用本人持有的 **BEP20 / BNB Smart Chain** 钱包地址。在 App 的提现地址管理选择 BEP20，经原有验证码流程绑定。该页本轮显示新地址保护期 **24 小时**；不能在未满足保护期时绕过校验。
2. 从可用钱包或交易所向 App 显示的专属地址转入 USDT-BEP20。普通自动入账单笔范围为 **10–100 USDT**，固定扣 **1 USDT**，至少 **15 个确认**。例如转入 30 USDT，正常净入账为 29 USDT。金额超出该范围按原规则进入待处理状态。
3. 核对真实 Cregis 交易和回调、链上日志、App 钱包及账单、D1 入金记录与充值单。不得用人工加款或模拟成功通知代替本步。
4. 链上出款仍须不同管理员在 D1 独立复核出款开关提案。TEST 本轮保留提案 #3，数据库出款位仍为关闭；代理人不能切换两个管理员账号代替独立审核。复核时需检查当前对账与风险资格。
5. 提现地址保护期结束、本人资格满足且出款已获独立批准后，在提现页提交小额申请，按 D2 原审批流程放行。该页本轮最低提现为 **20 USDT**，实际可提比例、手续费与净额以页面和订单快照为准。Cregis 出款钱包必须具备真实可用资金及网络手续费条件。
6. 只有供应商查询与 BSC canonical Transfer、地址、净额、至少 15 确认一致，原订单才结算预留并更新账单。检查钱包预留、订单、D4 流水和 D1/D3 相关记录的一致性。

## 中断后的恢复

- 回调投递失败：可在 Cregis 原交易的回调记录中重新推送；入金也有链扫描及完整对账补漏。回调收件持久化失败不会 ACK 成功。
- 重复通知：同一有效资金快照只计一次敞口和一次入账；冲突通知保留冻结和核查，不能通过重投绕过。
- 代付创建响应超时且回调缺失：在供应商处找到原单 CID，再到 D2 原提现详情核对 CID 和理由。系统独立查单匹配后继续观察原单。供应商不可查或证据冲突时保留预留，不重新创建代付。
- 低额、未归属、供应商/链冲突与重组：保持原有冻结、证据和人工调查边界。未定义完整退款、认领及冲正合同的情况，不能直接改余额或标记成功；本轮不新增这些资金处置规则。

## 尚不能用配置代替的验证

官方客服表示暂不支持无条件测试回调，因此真实已签名通知、实际充值入账和真实提现到账必须随受控真实交易验收。上述地址绑定、保护期、独立复核与钱包资金准备属于正常测试前置；本轮未进行真实转账。
